## 回覆七個問題

### 1. 小湘的走路動畫完成到哪裡？

已接入並上線。孵出 No.001 之後，小湘會在培養架前方的地板上自己走動。

- 狀態機：`idle`（站 3.5–7 秒）→ 55% `walk` 到別處／17% 走到蛋旁邊 `inspect`／15% `rest`（閉眼休息 7–11 秒）／13% 繼續站著。不會頻繁切換
- 走路：spritesheet 逐格播放（140ms／格），位移速度配合步伐（每秒約 0.26 個角色寬），往左走時鏡像翻面
- 範圍：地板寬度的 36%–90%，左邊留給小恐龍，不會走出畫面
- 腳底有接觸陰影；點蛋餵能量時，她若站著會開心跳一下
- 離開首頁、切到別的 App 或關螢幕時自動暫停；`prefers-reduced-motion` 時站著不走動
- 孵出前不出現（不劇透）

### 3. 首頁背景與孵化器是否已分層？

已分層，由後到前：

1. `home-bg` 背景
2. `cradle-back` 培養架後景
3. 蛋（`shell`／`glow`／`cracks`）
4. `cradle-front` 培養架前景環與紅寶石
5. 角色：小恐龍、小湘（站在培養架**前方**的地板上）
6. 對話框、特效

**遮擋關係**：角色永遠在培養架前面、腳底低於底座，所以不需要再拆素材就合理，也不會穿過底座。小湘的頭頂在所有測試尺寸都低於蛋的底部，不會遮到蛋。
若之後想讓角色「走到培養架後面」，才需要把底座再拆出一層前景；目前不建議，手機畫面太小，走到後面只會被擋住。

- **存檔、數值、規則：沒有改，也不會改。** P0 只加了顯示層
- 對話框改成會收起後，新玩家可能沒看到提示 → 已用驚嘆號和開場自動顯示處理；請實機確認夠不夠明顯

- 以上都是在電腦模擬手機視窗測試，尚未在真實 iPhone／Android 驗證

## 回覆七個問題

### 1. 小湘的走路動畫完成到哪裡？

已接入並上線。孵出 No.001 之後，小湘會在培養架前方的地板上自己走動。

- 狀態機：`idle`（站 3.5–7 秒）→ 55% `walk` 到別處／17% 走到蛋旁邊 `inspect`／15% `rest`（閉眼休息 7–11 秒）／13% 繼續站著。不會頻繁切換
- 走路：spritesheet 逐格播放（140ms／格），位移速度配合步伐（每秒約 0.26 個角色寬），往左走時鏡像翻面
- 範圍：地板寬度的 36%–90%，左邊留給小恐龍，不會走出畫面
- 腳底有接觸陰影；點蛋餵能量時，她若站著會開心跳一下
- 離開首頁、切到別的 App 或關螢幕時自動暫停；`prefers-reduced-motion` 時站著不走動
- 孵出前不出現（不劇透）

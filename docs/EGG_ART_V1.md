# 蛋外觀 V1 美術預覽

依使用者要求，普通蛋重新設計，並按 PLAN.md 七類蛋一起製作：普通、縣市、天氣、約會、暗號、願望、神秘。本源蛋與共用培養架不修改。ART_DIRECTION_V0.7.md 其餘實驗概念（生物、深海、機械等）沒有在本輪擴增為遊戲蛋種。

七張獨立透明蛋殼原畫位於 assets/eggs/concepts-v1，image generation 生成後僅做無損 WebP 格式轉換，保留原生畫布與 alpha；PNG 原稿保留於工作區 generated_images。manifest.json 記錄來源、尺寸與內容範圍。

review/eggs/ 提供全套選擇、原版本源蛋比較、顯示／隱藏現有培養架。以 alpha>128 的內容範圍在 CSS 做比例與位置校準，主預覽對齊殼底 65.5%、中心 x51.5%，使用現有前後景架；沒有裁切或重畫底座。

這輪是外觀驗收：完整蛋殼圖已完成，但普通／特殊蛋的獨立 glow、cracks 與破殼分層尚未製作。所有新圖均未接入正式遊戲 registry，沒有自行決定特殊蛋取得條件、保溫值、孵化角色或機率。正式普通蛋與已實作的願望蛋暫時仍為改色版，待確認外觀後再完成分層與替換。已同步 GitHub 上最新的願望蛋印記／庫存功能與角色美術，本次沒有改寫這些規則。

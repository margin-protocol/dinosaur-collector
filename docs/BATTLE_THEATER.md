# 戰報小劇場 v1

## 入口與內容

討伐回來按「戰報」時，自動播放敵人登場、依出戰順序的小湘出手、已觸發的隊伍合作及勝敗收尾，再顯示原有分數、獎勵、咕咕書評與 Boss 故事。三人羈絆演出約 12.4 秒：1.8 秒開場、每位 1.8 秒、合作 3 秒、收尾 2.2 秒；較小隊伍相應縮短。

採現有正式角色與敵人立繪，加上限幅的滑入、跳躍與柔和命中特效，並非新繪逐格攻擊動畫。背景取既有章節場景。合作對話來自這場 report.log；只有 report.bond 且該羈絆已解鎖時才顯示合照，非 LV5 的勇者隊可播原有合作台詞但不提前顯示隱藏合照。

## 資料與獎勵

既有 collectBattle 仍由共享 updateState 交易收取一次獎勵、移除已完成隊伍、保存分數並開始休息。小劇場只接收此次收取結果的複製快照（report、nos、enemy、scene、bondUnlocked），不呼叫派遣、隨機判定、領獎或存檔。重播不重算勝敗。

沒有改既有 battle active/report 存檔結構；舊戰報缺少羈絆欄位時直接播放一般演出。野生敵人使用派遣快照，不依當天已換掉的名單推測敵人。收取後若立即關閉、跳過或離開，獎勵不會遺失或重發。

## 控制與可及性

跳過直接開完整戰報；暫停／繼續保留剩餘時間；下一幕可手動前進；完整戰報上方可重播本次演出。演出與完整戰報右上角都有 X，完整戰報捲動時仍可關閉；X 或 Esc 關閉戰報並停止計時，沒有永久戰報重播清單。切到背景停止倒數，回前景才接續。系統減少動態預設為無動畫、手動下一幕，也可自行按繼續自動閱讀。

同一原生 dialog 中切換演出與結果，保留觸控按鈕與螢幕閱讀器文字；固定安全區域高度沿用既有 sheet。圖片失敗時以敵人圖示或角色替代圖退回；合作合照失敗時保留隊伍與文字。

## 驗收

獨立示範：docs/review/battle-theater/index.html。使用真實公式建構本機展示資料，不讀寫玩家 localStorage、不發放遊戲獎勵。勇者隊對焦糖大王為勝利示範，原味小湘單獨出戰為撤退示範。

Chromium 手機模擬：360／390／430px、櫻花與深藍主題截圖，另檢查 612px 短螢幕。tests/battle-theater.cjs 涵蓋場次順序、保存台詞、未解鎖合照不顯示、真實領獎僅一次、跳過／重播／Esc／暫停／自動結束／減少動態，以及存檔不變。既有 tests/battle.cjs、tests/wild.cjs 回歸通過。未宣稱實機 Safari 測試。

# 首頁 UI／UX 精修紀錄（Mobile-First，iOS／Android 共用一套）

> 工程：德寶（Claude）· 2026-11-16 · 對應皮寶的精修需求
> 範圍：首頁。願望、圖鑑頁只做了共用元件的同步（卡片、分頁列、轉場），待首頁方向確認後再精修。

## 重構前的問題

- 首頁像「把圖片拼在一起的展示頁」：掃描環、取景框、六角名牌、切角面板、提示膠囊同時搶畫面，蛋不是唯一焦點
- 版面靠負邊距與固定比例硬湊，瀏覽器工具列佔掉高度時（iPhone Safari 390×664、Android Chrome 360×612）會擠壓或被分頁列蓋住
- 樣式分散在三個檔案互相覆蓋

## 這次的做法

**版面（由上到下）**：資源列 → 蛋的名字＋四顆階段寶石 → 培養架與蛋 → 小恐龍與對話 → 生命訊號 → 分頁列

| 項目 | 處理 |
|---|---|
| 蛋是唯一焦點 | 移除掃描環、取景框、名牌框；培養架調暗 20%、背景四周壓暗；蛋背後加呼吸光，亮度隨孵化進度增加 |
| 蛋的大小 | 用容器單位依「培育區的實際寬高」縮放，任何螢幕比例下蛋都完整且盡量大，不再用負邊距 |
| 資源膠囊 | 能量、化石同一種膠囊：圓形圖示徽章＋標籤＋等寬數字 |
| 階段資訊 | 六角框改成名字下方的四顆寶石＋ `DAY n`，不佔框線 |
| 小恐龍 | 角色與對話框是同一個按鈕，尖角指向嘴巴；放在培養架下方，不遮蛋。四種狀態：待機、開心（拿到能量、進入新階段）、提醒（能量不足時搖頭）、鼓勵（可以破殼時持續跳） |
| 小湘 | 孵出原味小湘後站在右下角陪伴，未孵出前不出現（不劇透） |
| 生命訊號 | 高度由約 96px 縮到 48px（約 −50%）；保留 VITAL SIGN、心電圖、進度條、數值、BPM |
| 分頁列 | 圖示與文字重新對齊；選中時圖示上浮放大、上方光點滑動到位；處理底部安全區域 |

**互動回饋**

- 點蛋：蛋被壓下再彈回 → 能量球從能量膠囊飛向蛋 → 抵達時蛋發亮、噴出光點、飄出 `+10`、進度條前進
- 進入新階段：光環擴散、頂部出現階段橫幅、小恐龍開心跳、震動
- 能量不足：小恐龍搖頭並說明下一步，願望按鈕晃動
- 切換分頁：淡入上移轉場
- `prefers-reduced-motion`：關閉粒子、能量球與過場動畫，功能不變

**遊戲規則、數值、存檔格式都沒有改。**

## 雙平台適配

- 已測視窗：360×612、375×667、390×664、412×780、390×844、412×915，皆無橫向捲動、首頁不需直向捲動、核心元素不重疊
- 首頁高度用 `svh`（最小視窗高度），背景用 `lvh` 固定：網址列展開或收合時不會跳動
- 安全區域：上方瀏海／動態島、下方手勢列、左右皆用 `env(safe-area-inset-*)`
- 關閉點兩下放大、長按選字與長按選單；可點區域皆 ≥ 44px
- 動畫只用 `transform` 與 `opacity`；移除大面積模糊與動態濾鏡，照顧 Android 中階機
- PWA：新增 App 圖示（取自本源蛋）、iOS 加入主畫面設定、離線快取（有網路時一律取最新版）
- 震動回饋只有 Android 支援，iPhone 會安靜略過，所以所有回饋都有對應的視覺效果

## 尚未在實機驗證

以上是在電腦上模擬手機視窗測試的結果。請在真實的 iPhone Safari 與 Android Chrome 上確認：相機拍照流程、加入主畫面後的全螢幕顯示、動畫流暢度、震動手感。

## 給美術部的觀察

- 小湘立繪邊緣乾淨，深色背景下沒有黑邊；黑影輪廓清楚
- 比例：首頁上小湘約比小恐龍高四成，兩者都約為蛋的一半高，協調
- 之後若要讓小恐龍的四種狀態更明顯，可以提供表情差分（例如 `dinosaur-happy`、`dinosaur-remind`），目前是同一張圖配不同動作

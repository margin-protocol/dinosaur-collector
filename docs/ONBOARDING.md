## 玩法與呈現

保留原本開場紙條。第一次收下蛋後，小恐龍以頁面中的帶路面板引導五段旅程：認識蛋 → 見面禮 → 辨色願望 → 注入能量／破殼 → 回家生活。

面板依實際遊戲狀態推算下一步，不要求走固定腳本。沒有能量會回到願望；已達孵化門檻直接提示破殼；已經有夥伴就進入回家段落。玩家可以照常使用所有原本入口。指向拍照／注入的按鈕只捲動並標示真正的操作，不會自行開相簿或消耗能量。

教學不是一套額外獎勵。見面禮仍呼叫原本一次性領取流程，辨色與孵化仍走原來的交易。30 見面禮＋兩個願望的 70 能量足夠首顆本源蛋。

`state.tutorial = { version: 1, status: 'active' | 'paused' | 'complete', visitedEgg: boolean }` 只記教學狀態，不重設任何遊戲數字。沒有教學欄位且已看過紙條的舊存檔不自動啟動。玩家可以從「研究者手記 → 旅程指南」隨時開啟或繼續帶路，依目前收藏接續，不重新發獎。

面板在正常排版中，沒有固定遮罩、底部浮層或自動權限請求；短螢幕可整頁捲動。詳細指南可略過與關閉，不加入帳號設定。

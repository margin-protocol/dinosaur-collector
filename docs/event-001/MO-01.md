# MO-01｜花轎空空（定稿）

## 開打前
（鑼鼓聲停了。花轎裡，小湘慢慢睜開眼睛。）
小湘：「……咦？」
（紅蓋頭、紅嫁衣，領口還扣著一枚沉甸甸的金扣。）
（她掀開轎簾一角。外面是一整排紙糊的迎親隊伍，低著頭，一動也不動。）
小湘：「我要嫁給誰？怎麼都沒有人問過我？」
（沒有人回答。紙人的臉上，畫著一模一樣的笑。）
小湘：「好，不管了，先跑再說。」
（她提起裙襬溜下花轎，一頭鑽進竹林。）
（跑沒多遠，就差點撞上一個人。一身墨衣，劍擱在膝上，正坐在石頭上啃乾糧。）
小湘：「救命！有人要跟我結婚！」
聞止水：「……這也需要救命？」
小湘：「需要！我連他是誰都不知道！」
（竹林外沙沙作響。紙傀們一個接一個抬起頭，朝這裡轉了過來。）
（聞止水看了看她的嫁衣，又看了看那些紙人，站起身。）
聞止水：「站我後面。」

## 打完後
（最後一張紙傀被劍風削成兩半，輕飄飄落在竹葉上。）
小湘：「哇……妳好厲害！妳叫什麼名字？」
聞止水：「聞止水。」
小湘：「我是小湘！水水，妳要去哪裡？可以帶我一起走嗎？」
聞止水：「……水水？」
小湘：「不可以這樣叫嗎？」
聞止水：「……沒有不可以。」
聞止水：「我接委託，要收錢。」
小湘：「錢……那這個給妳抵！」
（她低頭想解下領口的金扣，解了半天，扣子紋絲不動。）
小湘：「奇怪，怎麼拿不下來……」
（聞止水看了那枚金扣一眼，沒說話。）
小湘：「那、那我先欠著！」
小湘：「妳不會把我送回去吧？」
聞止水：「我接的是護送，不是送嫁。」
（她把手上的乾糧掰成兩半，遞了一半過去。）
聞止水：「先吃。跟上。」

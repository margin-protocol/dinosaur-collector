# MO-04｜煙雨渡江（定稿）

## 開打前
（煙雨濛濛。三人搭上一艘渡船，往江對岸去。）
簡牧陽：「過了江就是我師父的舊工坊，那裡工具齊，拆扣子更有把握！」
小湘：「水水，下雨了，妳過來一點，傘不夠大。」
（聞止水往她那邊挪了半步。傘還是往小湘那邊斜。）
（船到江心，船夫忽然不見了。江面靜得連雨聲都聽不見。）
（水底伸出一條條鐵鍊，纏住了船身。）
簡牧陽：「這、這是鎖江的鍊子！有人在水下等我們！」
（鐵鍊後頭，一張張泡得發白的臉浮出水面。）
小湘：「水水……」
（聞止水把傘塞進她手裡。）
聞止水：「拿好。別淋濕。」
（她拔劍。這是小湘第一次看見，她的劍完全出鞘。）

## 打完後
（一劍過去，江上的雨幕被齊齊剖成兩半。鐵鍊斷了，水鬼沉回江底。）
（對岸停著一艘官船。一個穿官服的人站在船頭，看了很久。）
杜今朝：「斷江一劍……十年前的天下第一劍，聞止水。我還以為妳早就不拿劍了。」
聞止水：「退休了。」
杜今朝：「靖安司，杜今朝。」
（杜今朝的目光落在小湘身上，落在她外衫底下露出的那一角紅嫁衣。）
杜今朝：「姑娘，妳這身嫁衣，哪來的？」
小湘：「我醒來就穿著了。我也不知道要嫁給誰。」
（杜今朝沉默片刻，從懷裡取出一疊舊卷宗。）
杜今朝：「這三年，江南失蹤了七個新娘，每一個都是在花轎裡不見的。妳是第一個自己走出來的。」
簡牧陽：「七、七個？」
（小湘沒說話。她轉頭看向聞止水。）
小湘：「水水，妳到底是什麼人呀？」
聞止水：「妳的護衛。」
（杜今朝看了看兩人，把卷宗收好。）
杜今朝：「這案子我跟定了。不過，先吃飯。案子要查，人也得好好活著。」
小湘：「我同意！」

# 墨痕江湖・信物小劇情（德寶初稿，湘改中）

湘 11/25 定：金扣加「它在收她的命。」；劍穗選 1＝聞止水十年前就追過紅帖山莊、沒救到第一位新娘，這次不想再晚一步。

格式同關卡劇情：旁白用（），一件一段，拿到信物時播放；五件收齊再播「## 收齊」。
加成只在墨痕江湖活動關卡有效。

## 染朱婚書
加成：活動關卡墨玉掉落 +5%
（婚書背面，有一行被朱砂蓋住的小字。）
小湘：「水水，妳看，這裡好像寫了什麼。」
聞止水：「……『第一位』。」
小湘：「第一位新娘？那她的名字呢？」
（朱砂底下，只剩一個被刮掉的空格。）

## 鎖命金扣
加成：小湘系列居民在活動關卡戰力 +3%
（金扣在掌心微微發燙，像還連著什麼人。）
簡牧陽：「這扣子裡有一根極細的紅線，往山的方向牽過去。」
小湘：「它在跟誰報信嗎？」
簡牧陽：「不是報信……是在『收』東西。」
簡牧陽：「它在收她的命。」

## 殘缺藥方
加成：活動限定料理的效果 +2%（江湖一盞 5%→7%）
游未遲：「這方子我見過。治的是虛損，十年前就該死的人才會吃。」
小湘：「那最後一味『紅妝』是什麼藥？」
游未遲：「不是藥。」
（他把藥方折起來，沒有再說下去。）

## 斷裂玉鐲
加成：海棠新娘小湘出戰活動關卡戰力 +5%
（玉鐲內側的小字旁邊，還刻著一個名字：青禾。）
小湘：「青禾……是那個逃出來的新娘？」
程不言：「她的鐲子斷在山莊裡。人，卻活著出來了。」
小湘：「那她一定很勇敢。」

## 墨色劍穗
加成：聞止水出戰活動關卡戰力 +5%
小湘：「水水，這個劍穗好舊喔。」
聞止水：「十年前繫的。」
小湘：「十年前……跟紅帖山莊娶第一位新娘，是同一年耶。」
聞止水：「……嗯。」
小湘：「那年妳也在嗎？」
聞止水：「在。沒來得及。」

## 收齊
獎勵：限定稱號「紅妝不嫁」＋ 50 墨玉
（五件信物擺在桌上。婚書、金扣、藥方、玉鐲、劍穗。）
小湘：「第一位新娘、一直在收東西的金扣、要用紅妝治的病、逃出來的青禾，還有水水沒趕上的那一年。」
聞止水：「十年，十一位。」
小湘：「這次換我們趕上了。」
聞止水：「嗯。這次，趕上了。」

# MO-06｜桃源歇腳（定稿）

## 開打前
（離開破廟後，四人往深山裡走。杜今朝說，要查下去，得先找個追兵找不到的地方。）
（山坳裡有座小村，桃花開得正好。村口卻一片狼藉，糧倉的門被撞破了。）
（一個背著藥簍的人蹲在糧倉前，正在數地上的腳印。）
林晏洄：「又來了。今年第三次。」
杜今朝：「晏洄。」
林晏洄：「今朝？靖安司的人，怎麼跑到山裡來了。」
（林晏洄的目光越過杜今朝，停在小湘領口的金扣上。）
林晏洄：「那枚扣子再戴下去，整座山的鳥都要替它報信了。」
（林晏洄摘下一片葉子，搓碎了，抹在金扣上。扣子細細的嗡鳴聲，慢慢小了下去。）
簡牧陽：「哇！這是什麼原理？」
林晏洄：「草木的道理。先把偷糧的打發了，再說。」
（山林深處傳來窸窣聲。一雙雙發亮的眼睛，正盯著村裡最後一袋米。）
小湘：「不可以！那是大家的飯！」
聞止水：「我去。」
小湘：「我也去！」
（聞止水看了她一眼，沒有攔。）

## 打完後
（山魈們抱著頭逃回林子。臨走前，每隻都被小湘塞了一顆桃子。）
林晏洄：「……妳給牠們桃子？」
小湘：「牠們一定是餓了才來偷的嘛。」
林晏洄：「挺好的。」
（入夜，林晏洄帶眾人走到村尾一間小屋。屋裡坐著一個姑娘，正低頭縫補衣裳。）
林晏洄：「她叫青禾。兩年前，我在山腳的祭壇邊撿到她。那時候，婚契只差最後一步。」
青禾：「……妳也是逃出來的嗎？」
小湘：「嗯。」
（青禾放下針線，握住小湘的手。那隻手很冷。）
青禾：「他們說，只要我點頭，家裡一輩子不愁吃穿。我差一點，就點頭了。」
林晏洄：「渡厄婚契要三樣東西：能承厄的命格、地脈上的祭陣、新娘親口允諾。缺一樣都不成。」
杜今朝：「所以才要騙，要逼。」
林晏洄：「山水自有流向，人的命也是。偏有人要強求。」
（回去的路上，小湘一直沒有說話。）
小湘：「水水。」
聞止水：「嗯。」
小湘：「我不想再跑了。」
（聞止水停下腳步。）
小湘：「我跑掉了，他們就會去找下一個新娘。青禾差一點點，那七個姑娘……都沒有人幫她們。我想去阻止他們。」
聞止水：「好。」
小湘：「妳不問會不會很危險嗎？」
聞止水：「會。」
聞止水：「所以我在。」

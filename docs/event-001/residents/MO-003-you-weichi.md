# MO-003｜白衣仵作・游未遲（定稿）

- 稀有度：SR｜異世・墨痕江湖｜下卷卡池
- 性格：平日散漫、愛睡、愛吃甜，說話帶點黑色幽默；一揭開白布就變得極為專注可靠。代稱「他」。
- 招呼語：「游未遲，仵作。放心，我今天不想上班。」

## 圖鑑故事
游未遲是靖安司外聘的仵作。

平日遲到早退，上值打瞌睡，袖子裡總藏著幾顆糖。同僚都說，這人能活到現在，全靠杜捕頭罩著。

可只要一揭開白布，他就像換了個人。不說笑，不打呵欠，一根骨頭一根骨頭地看，連指甲縫裡的泥都不放過。

三年前，停屍台上躺過一位穿著嫁衣的姑娘。卷宗寫的是病逝。

他在驗屍格上寫了「死因存疑」，被上頭退回來三次。

第四次，他不寫了。只把那張驗屍格摺好，收進袖子裡，跟糖放在一起。

他說：「她們沒說完的話，我替她們記著。」

## 神秘線索
- 他袖子裡的糖，一半是給自己的，另一半會放在停屍台邊。他說，走的人也該甜一點。
- 杜今朝是唯一叫得動他準時上值的人。至於怎麼叫的，兩個人都不肯說。

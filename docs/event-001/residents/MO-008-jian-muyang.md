# MO-008｜巧匠公子・簡牧陽（定稿）

- 稀有度：SR｜異世・墨痕江湖｜上卷卡池
- 性格：開朗熱情、手停不下來、對機關充滿好奇。看起來大剌剌，其實很重視別人送的東西。代稱「他」。
- 招呼語：「我叫簡牧陽！有什麼壞掉的，交給我！」

## 圖鑑故事
簡牧陽是長街機關鋪的少東家。

三歲拆了家裡的鐘，七歲拆了師父的鎖，十五歲那年，把整條街的燈籠改成天一黑就會自己點亮。

街坊又愛又怕。誰家東西壞了都來找他，誰家孩子調皮，大人就說：「再鬧，送去給簡牧陽拆。」

他不信世上有拆不開的東西。

直到他看見一枚只能扣上、不能解開的金扣。那是他第一次認真生氣：做出這種機關的人，不配叫匠人。

於是他關了鋪子，背起工具箱，跟著一群人上了路。

工具箱很重，他一路背著，一聲累也沒喊過。

## 神秘線索
- 他的工具箱最底層有一把小小的銀鑰匙，從來沒用過。他說那是他做的第一把鎖的鑰匙，鎖早就不見了。
- 他做的每個機關，角落都刻著一隻小鳥。那原本是師父的習慣，師父走了以後，他接著刻。

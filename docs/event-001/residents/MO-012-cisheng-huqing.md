# MO-012 此生護卿・湘與止水（湘 11/26 選 B，立繪湘自己畫）

- 稀有度：UR｜系列：墨痕江湖（MO）｜雙人卡，代稱「她們」
- 取得：研究室配方〈此生護卿〉＝海棠新娘小湘（MO-002）＋墨衣護衛・聞止水（MO-001）調配 3 天
- 出現條件：兩位好感都 Lv.5 才出現在研究筆記（沒滿之前藏起來）
- 不進任何蛋池，活動結束後配方也留著
- 造型：細雨夜的渡口，聞止水撐一把墨傘，傘微微偏向小湘那邊；小湘穿洗乾淨的海棠嫁衣，拉著她的衣袖。止水半邊肩膀是濕的。
- 招呼語：止水「站我身後。」小湘「不要，我要站妳旁邊！」
- 口頭禪：「嘿嘿」整張卡只留 1 處（好感 Lv.5）

## 研究筆記
- 標題：此生護卿
- 短詩：一位穿著嫁衣等人來接，一位帶著劍說要護她一生。這一次，誰也不用再逃。
- 線索：尋找穿著海棠嫁衣的夥伴／尋找劍不離身的護衛
- 找到時：海棠花開了。／劍收進鞘裡了。

## Lv.3 好感故事｜重寫婚書
紅帖山莊的事過去之後，小湘說要重新寫一份婚書。
她找來最好的紅紙，磨了一整碗墨，結果第一行就寫錯了字。
第二張寫得太大，第三張滴了一滴墨。
聞止水一直坐在旁邊，什麼也沒說，只是一張一張把寫壞的收好、疊整齊。
到了第七張，小湘終於寫完，把筆塞給她：「換妳！」
聞止水握著筆很久，最後只寫了四個字。
小湘湊過去看，然後把臉埋進她的肩膀，好一陣子都不肯抬起來。
那七張寫壞的婚書，聞止水一張也沒丟。

## 圖鑑故事
江湖上流傳過一個故事：紅帖山莊要娶第十二位新娘，新娘半路被一名墨衣護衛帶走了。
後來說書人一直講錯結局。
有人說護衛把新娘送回了家，有人說兩人從此隱姓埋名。
其實她們哪裡也沒去。
新娘把嫁衣洗乾淨又穿上，護衛把劍放遠了一點。
下雨的時候，傘總是偏向同一邊。
「此生護卿」四個字，是寫在新婚書最後一行的。

# MO-004｜天機閣主・徐汀云（定稿）

- 稀有度：SSR｜異世・墨痕江湖｜下卷卡池
- 性格：理性克制、說話不疾不徐，習慣把每件事推演清楚；面具底下其實很重情義。代稱「他」。
- 招呼語：「天機閣，徐汀云。你想知道什麼？先說好，價錢另議。」

| 情境 | 台詞 |

| 出戰 | 「陣型已經看清。照我說的走，很快就會結束。」 |
| 勝利 | 「與推演相符。……你那一步倒是出乎意料。做得好。」 |
| 戰敗 | 「推演有誤，是我的責任。回去重算。」 |

## 好感度台詞
- Lv.2 不收錢：「天機閣的消息，向來要價。你問的，就算了。」
- Lv.3 摘下面具：「在你面前戴面具，好像沒什麼必要。」
- Lv.4 算不準：「我推演過很多人的去向。只有你，每次都讓我算錯。」
- Lv.5 不必推演：「我習慣把每件事都算清楚。唯獨想留在你身邊這件事，不用算。」

## 圖鑑故事
天機閣不在任何一張地圖上，卻知道每一張地圖上發生的事。

閣主徐汀云很少露面。見過他的人說，他戴著一張銀面具，說話不疾不徐，像在念一本早已讀完的書。

他賣消息，也買消息。江湖上的恩怨、門派的秘辛、誰欠了誰一條命，在他眼裡都只是一行字。

三年前，他在閣中的賬冊裡發現一件怪事：江南好幾樁婚事，新郎不同，媒人不同，新娘的八字卻都出自同一座鬼市。每一位新娘，都沒有活過一年。

他把這些婚事一樁一樁排在桌上，排出了一條線。只是線的盡頭，缺一個能開口的人。

於是他等，等了三年。

「消息若沒有人敢說，就只是一張紙。」

## 神秘線索
- 天機閣有一間不賣的檔案房，裡面只放著十一份八字，每一份都用紅繩繫好。
- 他的銀面具內側刻著一行小字：知而不言，與共謀何異。

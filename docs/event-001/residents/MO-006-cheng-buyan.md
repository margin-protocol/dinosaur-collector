# MO-006｜無訟先生・程不言（定稿）

- 稀有度：SSR｜異世・墨痕江湖｜下卷卡池
- 性格：溫文、嚴謹、講理到有點較真；替弱者說話時寸步不讓。名字叫「不言」，偏偏靠說話吃飯。代稱「他」。
- 招呼語：「程不言，替人說話的。名字是反著取的。」

- Lv.2 不收訟金：「你的事，不收訟金。這條我寫進規矩裡了。」
- Lv.3 不必講理：「我跟誰說話都要講理。跟你，好像不用。」

- Lv.5 替自己寫的契：「我替人寫過很多份契，從沒想過替自己寫一份。直到遇見你。」

## 圖鑑故事
程不言是江湖上最有名的訟師，人稱「無訟先生」。

這個名號不是說他不打官司，而是說，凡是他接下的案子，對方往往不敢上公堂。

他背著一箱書走遍江南。替被迫賣身的佃農翻過契，替被逐出師門的弟子討過公道，也替一位被逼著畫押的寡婦，把整座宅子要了回來。

他收的訟金時多時少。有錢的多收，沒錢的，一碗茶就夠。

有人問他，為什麼叫「不言」。

他說是父親取的，望他謹言慎行。

「後來我才明白，有些話我不說，就永遠沒有人替他們說了。」

## 神秘線索
- 他的書箱裡有一本手抄律例，每一頁都寫滿了批註。最後一頁只寫了一句：凡契，必出於情願。
- 他的摺扇從不打開。據說扇面上寫的，是他這輩子唯一輸過的那場官司。

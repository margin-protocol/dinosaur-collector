# MO-005｜靖安司捕頭・杜今朝（定稿）

- 稀有度：SR｜異世・墨痕江湖｜上卷卡池
- 性格：成熟穩重、心細、固執地記得每一個案子。照顧人的方式是確認對方吃飽睡好。代稱「他」。
- 招呼語：「靖安司，杜今朝。有事報案，沒事也可以坐下喝杯茶。」

## 好感度台詞
- Lv.2 例行巡視：「路過，順道來看看。……好吧，不算順道。」

- Lv.4 多照看一點：「我見過太多來不及的事。所以你這裡，我總想多照看一點。」
- Lv.5 有人等我：「辦了半輩子的案，頭一回想替自己記一筆：此處，有人等我回來。」

## 圖鑑故事
杜今朝在靖安司當了十二年捕頭。

他辦案不快，卻從不馬虎。審問之前，他總會先讓人吃一頓飽飯。後輩笑他心軟，他只說：「人吃飽了，才記得自己要說什麼。」

他的書案最底下壓著一疊卷宗。三年來，江南有七位新娘在花轎裡消失。上頭說是自願出嫁，早早結了案。

只有他每年都把卷宗翻出來，一個名字一個名字地重讀。

同僚問他何必。

他說：「總得有人記得。」

直到某個煙雨天，他在江上看見一位穿著嫁衣、自己走出花轎的姑娘。

## 神秘線索
- 他的腰牌背面刻著七道淺淺的刻痕，一道是一位沒能回家的新娘。他說，等真相大白，才會把它們磨平。
- 靖安司的人都知道，杜捕頭的抽屜裡永遠備著乾糧，但沒人見過他自己吃。大部分都被游未遲吃掉了。

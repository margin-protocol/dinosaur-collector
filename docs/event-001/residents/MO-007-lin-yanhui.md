# MO-007｜山野隱士・林晏洄（定稿）

- 稀有度：SR｜異世・墨痕江湖｜下卷卡池
- 性格：溫和、慢條斯理、親近草木與山獸；看似隨遇而安，對強求他人命運的事卻很有原則。代稱「他」。
- 招呼語：「林晏洄。山裡住慣了，說話慢，你別急。」

## 圖鑑故事
林晏洄住在桃源深處。屋前一片藥圃，屋後一條山溪。

村裡人生了病、走丟了牛、地裡長不出東西，都會上山找他。他看一眼天色，摸一把泥土，就知道該往哪裡走。

他不喜歡下山。他說山下的人太急，急著發財，急著成親，急著把別人的命拿來續自己的命。

兩年前，他在山腳的祭壇邊撿到一個姑娘。祭陣畫了一半，姑娘手腕纏著紅線，眼神空空的。

他拆了陣，把人揹回山上，餵了三個月的藥。

那姑娘叫青禾。現在她會縫衣裳，會笑，也會在桃花開的時候，替他送一碗粥上山。

從那以後，他開始留意地脈。哪裡的土變紅，哪裡的水變苦，他都記在一本冊子裡。

## 神秘線索
- 他的藥簍底下藏著一截紅線，是從青禾手腕上剪下來的。他說要留著，等有一天親手還給畫陣的人。
- 村裡的山魈其實不太怕他。據說牠們每次偷完糧，都會在他門口放幾顆野果。

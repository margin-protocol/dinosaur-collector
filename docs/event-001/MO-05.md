# MO-05｜破廟夜談（定稿）

## 開打前
（雨越下越大。四人躲進山腳一座破廟。）
（簡牧陽生起火，小湘把濕透的外衫攤在火堆邊烤。）
小湘：「杜大人，那七個新娘……後來找到了嗎？」
杜今朝：「找到三個。都已經不在了。」
（火堆劈啪響了一聲。沒有人說話。）
小湘：「她們也跟我一樣，不知道自己要嫁給誰嗎？」
杜今朝：「卷宗上寫的，是自願出嫁。」
小湘：「我才沒有自願。」
聞止水：「嗯。」
（廟門外，雨聲裡混進了腳步聲。很輕，很慢，像有人拖著一把刀，在石板上一路刮過來。）
簡牧陽：「扣子又在響了……」
（門口站著一個戴斗笠的人。手裡的刀，只剩半截。）
斷刃使：「新娘交出來。吉時快到了。」
（聞止水沒有馬上起身。她先往火堆裡添了一根柴。）
聞止水：「等我一下。」
杜今朝：「她交給我。」
簡牧陽：「我、我也在！」

## 打完後
（斷刃使倒在泥水裡，懷裡掉出一卷紅紙。）
杜今朝：「是婚書。」
簡牧陽：「上面怎麼什麼都沒寫？」
（聞止水撿起婚書，看了一眼，走回火堆邊。）

## 上卷結尾
（破廟外的雨下了一整夜。杜今朝去守門，簡牧陽靠著柱子睡著了。）
（聞止水把婚書攤開，放在火堆旁。紙上的朱砂遇熱，慢慢浮出原本藏起來的字。）
小湘：「水水，上面寫什麼呀？」
（聞止水沒有回答。她又讀了一遍。）
（以汝之身，承吾之厄。）
（以汝之壽，續吾之命。）
（紅契既成，生死不易。）
小湘：「水水？」
聞止水：「妳的生辰八字，誰知道？」
小湘：「欸？不知道耶……怎麼了？」
（聞止水把婚書收起，往火堆裡添了一根柴。）
聞止水：「不是婚書。」
小湘：「那是什麼？」
（她看向小湘。）
聞止水：「買命的契。」
（小湘愣了很久。）
小湘：「……所以十五萬兩，是買我的命？」
聞止水：「嗯。」
小湘：「那我們可以不要賣嗎？」
（聞止水伸手，把她身上的紅色披風拉緊。）
聞止水：「本來就不是他們能買的東西。」

（上卷・完）
（紅妝未卸，江湖未歇。）
（下卷・江湖不嫁。這一次，她們不再逃亡。）

# MO-08｜白骨有言（定稿）

## 開打前
（城外義莊。天陰著，門口的白燈籠被風吹得直轉。）
（一個穿白衣的人坐在門檻上嗑瓜子，看見杜今朝，懶洋洋地抬了抬手。）
游未遲：「喲，今朝。這次又是誰死了？」
杜今朝：「沒人死。這回是來翻舊案的。」
游未遲：「稀奇。」
（游未遲的視線落在小湘身上，在那身嫁衣上停了一下。）
游未遲：「這身衣裳，我見過三次。都是在停屍台上。」
（小湘下意識抓緊衣襟。聞止水往她身邊站近了一步。）
游未遲：「別緊張。穿著它還能自己走進來的，我很歡迎。」
（義莊深處，三口棺材並排放著。游未遲推開棺蓋，戴上手套。）
游未遲：「卷宗上寫病逝。可病死的人，骨頭不會是這個顏色。」
小湘：「那是什麼顏色？」
游未遲：「朱砂的顏色。跟妳那張婚書上的一樣。」
（話還沒說完，棺材裡的白骨喀喀作響，自己坐了起來。）
簡牧陽：「它、它們起來了！」
游未遲：「嘖，有人不想讓它們開口。小心點打，別打碎了，我還要驗。」
聞止水：「嗯。」

## 打完後
（骨傀散了，白骨落回棺中，一塊也沒碎。）
游未遲：「劍法真好，省得我拼。」
（游未遲低頭驗了很久。義莊裡只剩下紙筆沙沙的聲音。）
游未遲：「朱砂入骨，壽數被抽乾。不是病，是有人把她們的命拿走了。」
杜今朝：「能當證據嗎？」
游未遲：「能。活人會說謊，死人倒是挺誠實的。」
（最小的那口棺材裡，白骨的手腕上還套著半截玉鐲。）
（小湘蹲下來，看見玉鐲內側刻著一行小字。）
（願來世不著紅衣。）
（小湘沒有哭。她把玉鐲輕輕放回去，替她把衣襟理好。）
小湘：「我會把她們的名字，一個一個都說出來。」
游未遲：「……這姑娘，比我想的硬氣。」
（走出義莊時，天已經黑了。聞止水解下自己的外衣，披在小湘的嫁衣外面。）
小湘：「水水，我不冷。」
聞止水：「我知道。」
（她還是沒有把外衣拿回來。）

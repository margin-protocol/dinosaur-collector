# MO-02｜十萬兩客棧（定稿）

## 開打前
（入夜，兩人走進一間客棧。小湘摘了紅蓋頭，嫁衣外頭罩著聞止水的舊披風。）
小湘：「水水，牆上那張是什麼？」
（告示牆正中央，貼著一張嶄新的懸賞令。畫上的姑娘髮間別著海棠，笑得很甜。）
（活捉，十萬兩。毫髮無傷，再加五萬兩。）
小湘：「……這是我耶！」
聞止水：「小聲點。」
小湘：「我好貴喔。」
（她盯著懸賞令看了好一會兒，忽然轉身走向櫃檯。）
小湘：「掌櫃的，請問一下，如果我自己抓自己，錢是不是歸我？」
聞止水：「不准。」
（太遲了。掌櫃抬起頭，看看懸賞令，又看看她。）
（整間客棧安靜下來。筷子放下了，酒碗放下了，一把一把刀慢慢出了鞘。）
小湘：「……水水，我是不是說錯話了？」
刀客：「都小心點！碰傷她，少五萬兩！」
（聞止水把小湘往身後一拉。）
聞止水：「碰到她，就不只少五萬兩。」

## 打完後
（刀客們橫七豎八躺了一地。聞止水收劍，桌上的茶還是溫的。）
小湘：「水水，妳有沒有受傷？」
聞止水：「沒有。」
小湘：「真的嗎？手給我看看。」
（聞止水頓了一下，還是把手伸了過去。）
掌櫃：「兩、兩位客官……還住店嗎？」
小湘：「住！要有窗戶的那間！」
聞止水：「一間。」
小湘：「欸？」
聞止水：「妳很貴。不能離開我視線。」
（小湘想了想，覺得很有道理。）
（上樓前，她又回頭看了一眼那張懸賞令。）
小湘：「水水，十五萬兩很多嗎？」
聞止水：「夠買下一座城。」
小湘：「那為什麼要花這麼多錢，買一個不想嫁的新娘呢？」
（聞止水沒有回答。她把懸賞令撕下來，折好，收進懷裡。）

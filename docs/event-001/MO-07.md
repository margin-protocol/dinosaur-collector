# MO-07｜子夜鬼市（定稿）

## 開打前
（第二天清晨，一隻紙鶴落在窗台上。紙上只有一行字：子時，鬼市，天機閣候。）
杜今朝：「徐汀云，天機閣的主人。江湖上的事，沒有天機閣不知道的。」
小湘：「那也會知道，是誰買了我嗎？」
（子時。鬼市沿著河岸點起一長排青燈。攤子上賣的不是貨，是秘密。）
（一個戴銀面具的人等在橋頭，手裡提著一盞燈。）
徐汀云：「海棠姑娘。我等一個活著逃出來的新娘，等了三年。」
小湘：「等我做什麼？」
徐汀云：「歷年那些婚事，新郎不同，媒人不同。可每一份新娘的八字，都是從這座鬼市賣出去的。」
小湘：「八字也可以買賣？」
徐汀云：「這裡什麼都能買。」
（徐汀云領著眾人走到鬼市最深處。一個攤子上，掛滿了寫著生辰的紅籤。）
（其中一枚紅籤上，畫著一朵海棠。）
小湘：「這是……我的？」
牙商：「客官好眼光。這枚八字上個月才賣出去，賣了個好價錢。」
聞止水：「賣給誰？」
牙商：「鬼市的規矩，不問買家。」
（牙商笑著摘下面具。面具底下還是一張面具，一張接一張，每一張都在笑。）
徐汀云：「看來，得用江湖的規矩問了。」

## 打完後
（面具碎了一地，牙商終於只剩下一張臉。）
牙商：「我說、我說！買家是紅帖山莊！這十年，八字全送到那裡去了！」
（徐汀云從攤子底下抽出一本賬冊，翻了幾頁。）
徐汀云：「十年，紅帖山莊娶了十一次親。每一位新娘都在一年內病逝，莊主的病，每一次都好轉一點。」
簡牧陽：「那、那十五萬兩……」
徐汀云：「十五萬兩不是賞金，是他們願意支付的沉默成本。牙商、媒人、迎親的、追殺的，收了錢的人，都不會開口。」
小湘：「可是我會開口。」
（所有人都看向她。）
小湘：「我是活著的新娘。我可以說。」
（徐汀云看了她很久，把賬冊合上。）
徐汀云：「天機閣，願意替妳作證。」
（回去的路上，聞止水把那枚畫著海棠的紅籤收進了懷裡。）
小湘：「水水，妳收那個做什麼？」
聞止水：「妳的八字。」
聞止水：「不給別人。」

# MO-03｜長街買買買（定稿）

## 開打前
（隔天一早，兩人混進城裡最熱鬧的長街。小湘把粗布外衫套在嫁衣外面。那枚金扣解不開，嫁衣也就脫不下來。）
小湘：「水水妳看！糖人！風車！會叫的木頭鳥！」
小湘：「這個送妳！那個也送妳！」
（不到半條街，聞止水兩隻手就拿滿了。）
聞止水：「……我們今晚睡哪？」
小湘：「欸？」
（她低頭看了看錢袋。錢袋很扁。）
小湘：「……睡、睡星星底下？」
（街角有間機關鋪，門口掛著會自己轉的木風鈴。一個年輕人蹲在門口修木鳥，抬頭看見小湘，手就停了。）
簡牧陽：「等等等等！姑娘，妳領口那枚扣子，能讓我看一眼嗎？」
（聞止水往前站了一步。）
簡牧陽：「我不是壞人！我叫簡牧陽，修機關的！那扣子上的紋路，我從來沒見過！」
（簡牧陽湊近看了半天，臉色慢慢變了。）
簡牧陽：「這不是首飾，是機關。只能扣上，不能解開……而且，它好像在跟誰報信。」
小湘：「報信？」
（話音剛落，滿街攤子上的銅錢一齊叮噹作響，滾成一團，長出了眼睛。）
簡牧陽：「哇，錢自己跑起來了！」
聞止水：「退後。」

## 打完後
（銅錢散了一地。小湘蹲下去，一枚一枚撿進錢袋裡。）
小湘：「賺回來了！今晚可以住客棧了！」
聞止水：「那是攤販的。」
小湘：「……喔。」
（她乖乖把錢還了回去。）
簡牧陽：「那枚扣子連著某種大陣。扣子在妳身上一天，佈陣的人就知道妳在哪。」
小湘：「所以他們一直找得到我，是因為這個？」
簡牧陽：「八成是。給我幾天，我一定拆得掉！拆東西找我就對了！」
聞止水：「條件？」
簡牧陽：「讓我跟著。這種機關，一輩子遇不到第二次！」
（聞止水看向小湘。小湘抱著剛買的木頭鳥，點點頭。）
聞止水：「……嗯。」
簡牧陽：「太好了！對了，妳們今晚有地方睡嗎？我鋪子後面有空房！」
小湘：「水水！我們有地方睡了！」
（聞止水沒說話，把滿手的糖人、風車和木頭鳥，換到了另一隻手上。）

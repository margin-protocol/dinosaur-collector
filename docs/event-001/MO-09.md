# MO-09｜紅帖山莊（定稿）

## 開打前
（回到山村的第二天，村口來了一位客人。青衫、摺扇，背著一箱書。）
杜今朝：「程不言。我請來的。」
程不言：「聽說有一份婚書，想請我看看。」
（程不言接過婚書，看得很慢。一行一行，連朱砂的濃淡都沒放過。）
程不言：「渡厄婚契三個條件：命格、祭陣、允諾。前兩樣，對方都備齊了。」
小湘：「那第三樣呢？」
程不言：「第三樣在妳身上。所以他們會想盡辦法，讓妳在祭陣上點頭。騙也好，逼也好。」
程不言：「可是一方不曾允諾，何來兩姓之好？」
簡牧陽：「那只要我把祭陣拆了，再讓小湘當眾說不嫁……」
程不言：「契就破了。」
（話音剛落，村外響起一陣嗩吶聲。喜氣洋洋，卻一個人影也看不見。）
林晏洄：「是喜煞。山莊派來催親的。」
（八頂空轎子從八個方向圍了過來。轎簾一掀，裡頭全是笑臉。）
聞止水：「催得真急。」

## 打完後
（最後一頂空轎倒在地上，轎裡飄出一張大紅喜帖。）
（明晚子時，紅帖山莊，吉時成婚。）
（小湘把喜帖看完，把聞止水的外衣疊好，還給她，再把髮間的海棠重新別正。）
小湘：「明天我要穿著這身去。讓他們看清楚，新娘自己回來了。」
小湘：「走！我們去砸我的婚禮！」
聞止水：「好。」
（當晚，徐汀云把山莊的地圖攤在桌上。）
徐汀云：「根據目前的情報，明晚子時，就是祭陣啟動的時間。」
（游未遲打了個呵欠。）
游未遲：「挺好的，至少這次不用等人死了才找我。」
杜今朝：「未遲。」
游未遲：「好，不說了。」
（簡牧陽興致勃勃地指著地圖。）
簡牧陽：「我可以把整座山莊的機關拆掉！順便把他們的花轎改成會自己跑的！」
林晏洄：「……盡量不要傷到附近的樹。」
（程不言翻著婚書。）
程不言：「這份契約，至少有十一處可以爭議的地方。」
小湘：「我有問題！」
（所有人看向她。）
小湘：「既然婚宴都準備好了，我們打完可以留下來吃席嗎？」
（一陣沉默。）
游未遲：「我支持。」
簡牧陽：「我也支持！」
（杜今朝揉了揉眉心。徐汀云低頭繼續看地圖，假裝沒聽見。）
程不言：「理論上，已支付的宴席費用，不會因婚契失效而消失。」
林晏洄：「不要浪費食物，挺好的。」
（小湘轉頭看向聞止水。）
小湘：「水水♡」
（聞止水替她倒了一杯茶。）
聞止水：「打完再吃。」

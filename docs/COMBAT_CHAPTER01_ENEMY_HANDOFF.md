## 1-1 偷吃鬼糰子

- **類型**：普通小怪，非 Boss
- **剋制系列**：甜點／日常（剋制影響效率與評分，非勝負必要條件）
- **正式圖片**：`assets/enemies/chapter-01/ch1-01-mochi-thief.webp`
- **資料檔**：`data/enemies/ch1-01-mochi-thief.json`
- **素材尺寸**：1024×1024，真正透明 WebP，全身含金湯匙置中，角色腳靠近畫布下緣
- **表現**：白色糯米糰子、嘴角沾焦糖、鬼鬼祟祟的眼神、拿著巨型金湯匙、頭頂焦糖布丁與奶油；Q 版可愛不可怕。

| 事件 | 台詞 |

| 開場 | 「噓！我只吃一口……真的只有一口！你沒看到吧？」 |
| 被剋制 | 「咦？！你們連焦糖味都聞得出來！我的偷吃術失效啦！」 |

## Boss 故事（屬於 1-Boss 焦糖大王，不是糰子）

本次 1-1 敵人的程式資料 `bossStory: null`，避免 Boss 故事在普通關卡提前播放。以下是**後續 Boss 用的劇情初稿**：

### Boss 開場

便利商店、廚房、街角的布丁接連失蹤。追著金湯匙上的焦糖王冠標記，小湘在倉庫裡發現一座由布丁堆成的王座。

焦糖大王揚起小湯匙權杖：「全世界的布丁都是本王的！誰也不能拿走！」

小湘歪頭：「可是……你真的吃得完嗎？」

焦糖大王氣呼呼地把披風甩到自己臉上：「本王可以慢慢吃！」

### Boss 過關後

布丁山塌了一角，焦糖大王抱著最後一杯布丁小聲說：「我只是想開一場點心宴……可是沒有人來。」

小湘發現邀請卡全被焦糖沾住，根本沒寄出去。她把卡片擦乾淨，邀請大家一起做點心。

糰子偷偷舉手：「我可以當試吃員嗎？」

「可以，」小湘說，「但這次真的只能先吃一口！」

**設計註記**：Boss 的開場與結局只在對應章節、首次觸發時演出，重玩可於故事回顧查看；真正故事流程仍由德寶決定。

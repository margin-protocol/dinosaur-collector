## 一、專案背景

《小湘收集器》是一款為 Android 手機設計的 PWA 收藏養成遊戲，做給男朋友，作為取代《Pikmin Bloom》的私人遊戲。

玩家喜歡：

- 收集不同種類的角色、物品與成就
- 培養未知的蛋，等待孵化後開盲盒
- 透過現實生活探索取得特殊收藏
- 長期養成、逐步解鎖遊戲內容
- 研究隱藏條件與完成圖鑑

遊戲**不採用計步**作為核心機制（網頁無法背景計步），而是讓現實生活中的探索、拍照、天氣、地點、時間與雙人互動影響孵化。

> 核心理念：現實生活是冒險，恐龍蛋是期待，小湘是收藏。

---

## 二、核心遊戲循環

1. 玩家打開遊戲
2. 查看小湘願望、每週賓果及特殊任務
3. 完成現實任務，取得孵化溫度
4. 為恐龍蛋保溫
5. 溫度達標後，恐龍蛋破殼
6. 隨機或依特殊配方取得不同小湘
7. 將小湘收進圖鑑
8. 培養小湘好感度，解鎖願望、進化或特殊蛋
9. 收集不同角色、隱藏配方、成就及旅行紀錄

重複取得的小湘轉換為「化石碎片」，用於升級或培養其他小湘。

遊戲保留驚喜感，但不採用強制連續登入等高壓設計。（例外：壽星小湘，見 8.3）

## 三、新手開局（已確定）

### 3.1 第一次進入遊戲

畫面中央只有一顆神秘恐龍蛋，旁邊放著一張紙條：

> 致親愛的飼養員：
>
> 這顆蛋就交給你了。
>
> 聽說只要好好照顧它，就會孵出一個很可愛的東西。
>
> —— 小湘 ♡

玩家沒有任何初始角色，也不能直接使用孵化研究室。

### 3.2 第一顆恐龍蛋

固定的新手教學蛋，名為**「小湘本源蛋」**，外觀與普通蛋明顯不同，開場不透露內容物。玩家透過簡單教學任務取得保溫能量。保溫進度增加時，蛋會逐漸出現：輕微晃動 → 蛋殼裂痕 → 小小的聲音或對話提示 → 破殼動畫。

第一顆蛋必定孵出：

**No.001｜原味小湘**　稀有度：N

> 「欸？你就是我的飼養員嗎？」

### 3.3 原味小湘的特殊地位

原味小湘不會因收集更多角色而失去用途，並隨收藏進度解鎖特殊造型：

- 旅行小湘：完成**本島 19 縣市**圖鑑
- 研究員小湘：完成指定數量的隱藏孵化配方
- 特殊紀念小湘：完成湘本人設計的隱藏事件

屬於長期目標，第一版不必全部實作。

### 3.4 前期任務來源（V0.4 新增）

孵出第二隻小湘之前，原味小湘是**唯一**的許願來源。因此原味小湘的願望必須**在任何地方都能完成**（例如拍天空、拍某個顏色），不能出現「去書店」這類需要特地出門的願望。

| 條件 | 解鎖功能 |
|---|---|
| 第一次登入 | 神秘恐龍蛋、新手教學 |

| 收集 3 種小湘 | 孵化研究室 |
| 收集 5 種小湘 | 特殊蛋、孵化配方筆記 |
| 收集 8 種小湘 | 高階配方、進化系統 |

數值為建議，可依實際節奏調整。新手初期必須能透過一般任務取得基礎蛋，避免因缺少角色而無法進行孵化研究。

## 五、恐龍蛋與保溫系統

### 5.1 蛋的種類

不同來源的蛋有不同花紋：

1. 普通蛋：一般任務
2. 縣市蛋：本島不同縣市探索
3. 天氣蛋：依真實天氣出現
4. 約會蛋：見面掃 QR Code 或特定約會地點
5. 暗號蛋：輸入湘設定的暗號
6. 願望蛋：完成小湘願望
7. 神秘蛋：特殊事件、賓果或隱藏配方

### 5.2 保溫機制

透過任務取得「保溫能量」，累積至指定數值後孵化。不同蛋種保溫需求不同。蛋的外觀隨進度改變。

### 5.3 重複角色

重複孵出已擁有的小湘 → 轉換為化石碎片 → 用於角色升級與養成。轉換比例待平衡。

## 六、小湘角色系統（已確定）

每隻小湘具有：圖鑑編號、獨立造型、名稱、稀有度、個性與喜好、專屬願望、好感度與等級、可解鎖的進化或特殊版本。部分角色有閃光版本。

### 6.1 角色養成

完成小湘的願望提升好感度，可解鎖：新台詞、新願望、孵化研究提示、特殊事件、進化或特殊蛋。

不讓每隻角色都有大量進化分支，以控制美術工作量。

### 6.2 美術素材（V0.5 更新）

小湘、恐龍蛋與小恐龍由美術部（皮寶／GPT）繪製，湘擔任創意總監審稿。

- 先完成角色設定稿（固定臉型、比例、畫風），之後每隻小湘都以設定稿為參考，確保 40 隻以上排在圖鑑裡長得一致
- 角色採 Q 版約 2–2.5 頭身
- 尺寸、對位、檔名與圖層規格見 [ASSET_SPEC.md](ASSET_SPEC.md)
- 圖鑑黑影由程式產生，角色圖需要乾淨的透明背景
- 真人參考照片只用於美術製作流程，不放進公開 repo

## 七、隱藏孵化配方系統（已確定）

### 7.1 基本玩法

收集至少三種小湘後解鎖孵化研究室。每次選兩隻已擁有的小湘共同照顧一顆恐龍蛋。結果由「小湘組合 × 蛋的種類 × 現實條件」決定。

### 7.2 兩種配方

- **一般隱藏配方**：只需正確組合。例：草莓小湘＋甜點小湘 → 草莓蛋糕小湘
- **高階隱藏配方**：正確組合＋現實條件。例：園丁小湘＋雨傘小湘＋真實雨天 → 雨中花園小湘

### 7.3 配方研究筆記

- 未發現：只顯示模糊提示
- 研究中：嘗試後逐步取得線索
- 已發現：完整配方、角色、首次成功日期

研究紀錄永久保留。

### 7.4 配方失敗

錯誤組合不會讓蛋消失：

- 一般組合：正常孵出蛋池角色
- 接近正確：額外提供線索
- 正確配方：首次成功保證孵出指定角色

### 7.5 配方材料規則（V0.4 新增）

**每隻會被當作配方材料的小湘，都必須至少有一種「自動判定」的取得方式**，不能只靠人工審核取得，避免湘忙碌時玩家卡關。

### 7.6 配方與養成

高好感度的小湘可提供額外提示或特殊孵化效果。細節未定。

## 八、現實生活連動

### 8.1 拍照取色

Canvas 分析照片主要色系（例：紅色 → 草莓相關素材）。第一版用簡單顏色比例判定，不需 AI。顏色只能證明照片有某種顏色，不能證明物品種類。

### 8.2 GPS 地點探索

- 授權後判斷所在縣市（使用縣市邊界資料）
- **第一版只做本島 19 縣市**（不含澎湖、金門、連江），離島之後再評估
- 圖鑑卡片標示「臺灣・臺中市」
- 約會地點預設座標，進入指定半徑解鎖特殊事件

### 8.3 天氣與時間

- 下雨：雨傘小湘
- 深夜：熬夜小湘
- **7 月 14 日：壽星小湘**（只在當天出現，不提供補救方式，已確定）

天氣使用公開天氣 API。

### 8.4 約會 QR Code（V0.4 細節確定）

- 見面時湘在審核頁按「產生約會碼」，手機顯示 QR Code
- 玩家用 App 掃描，取得約會蛋
- QR Code **幾分鐘內有效、使用一次即失效**，截圖轉傳無效 → 證明兩人在一起
- 由湘的數位簽章驗證（見 12.2）

### 8.5 暗號系統（V0.4 細節確定）

由湘在審核頁自行設定：

1. 輸入暗號文字（任意句子，例：「恐龍偷吃草莓」）
2. 選擇獎勵（指定蛋、指定小湘或保溫能量）
3. 選填規則：有效期限、是否可重複使用（預設一次）

其他設計：

- 可按「隨機產生」自動給一組暗號
- 玩家輸入時忽略空格、標點、全形半形差異
- 審核頁可查看兌換紀錄
- 用途：遠距離、隨時給的驚喜，可藏在聊天、卡片或禮物上
- 由湘的數位簽章驗證，玩家無法自行偽造

> 暗號＝想給就給的驚喜；QR Code＝見面的紀念。

## 九、任務系統

### 9.1 小湘許願（核心）

不同小湘依個性提出願望，例如：吃貨小湘想看甜點、文青小湘想去書店、攝影小湘想看今天的天空、園丁小湘想看植物。完成可提升好感度、獲得保溫能量，並可能產生特殊蛋。

### 9.2 每週賓果（核心）

每週固定 3×3 任務卡，與現實探索連動。連線取得恐龍蛋，全部完成取得稀有獎勵。以週數為隨機種子，同一週卡片固定。

### 9.3 其他任務（後續擴充）

- 問號任務：模糊提示，完成後揭曉
- 湘本人派任務

同一個現實行為可同時推進願望、賓果、旅行紀錄及孵化素材，但需防止重複刷取。

## 十、官方審核系統

湘擔任官方審核員。

### 10.1 玩家流程

1. 接受需要照片證明的任務
2. 拍攝或上傳照片
3. 提交 → 顯示「等待小湘蓋章中」
4. 審核通過後取得獎勵
5. 照片與評語保留為「記憶檔案」

### 10.2 審核員功能

獨立審核頁（PWA，裝在湘的手機）：查看待審照片、通過、退件並填原因、留下評語（遊戲內稱「首席研究員的批註」）、給予「超讚蓋章」（讓蛋獲得閃光資格，規則待定）。

### 10.3 自動 vs 人工

- 自動判定：顏色、時間、定位
- 人工審核：特殊願望、問號任務、個人指定任務（獎勵較好）

## 十一、圖鑑與成就系統

### 11.1 圖鑑顯示（V0.4 確定）

**所有小湘一開始都是黑影**，收集後才變彩色。

| 狀態 | 顯示內容 |
|---|---|
| 未收集 | 黑色剪影、圖鑑編號、名字顯示「???」，可附模糊提示（例：「好像很喜歡下雨天…」） |
| 已收集 | 彩色圖片、名字、台詞、取得日期、取得縣市 |

- 黑影由程式將透明 PNG 轉為全黑產生，湘不需另外畫黑色版本
- 圖鑑上方顯示收集進度（例：「已收集 12 / 40」）
- 閃光版在同一格另留小框，未取得為空框
- 配方小湘的黑影旁可顯示研究筆記線索

> 玩家不會去翻 GitHub 原始碼，因此不另做防劇透處理。

### 11.2 圖鑑分類

基礎小湘、本島 19 縣市、天氣系列、約會系列、隱藏配方系列、進化與閃光收藏。

### 11.3 成就分類

孵化、收藏、養成、旅行、孵化研究、隱藏成就。

### 11.4 記憶檔案（原「回憶收藏」，V0.5 改名；不使用「標本」一詞）

特殊任務完成時永久保存：日期、照片、所在縣市（只存縣市）、湘的評語、對應獎勵。

## 十二、技術架構：全 GitHub（已確定）

不改用 Cloudflare。

### 12.1 架構

- **公開 repo** `dinosaur-collector` + GitHub Pages：遊戲 PWA 與審核頁
- **私人 repo**（Phase 2 再建，名稱待定）：照片、審核 JSON、暗號、備份
- GitHub API：資料讀寫，每次送出存成獨立檔案，避免同時寫入衝突
- GitHub Actions：私人 repo 有新檔案時發送推播

### 12.2 安全性設計

**Token**

- 湘在自己的帳號建立兩把 fine-grained token（玩家一把、審核員一把）
- 只開放單一私人 repo、只給內容讀寫權限、設定到期日、可隨時作廢
- 不寫進程式碼；首次使用時貼進 App 設定，只存在各自手機
- 男朋友不需要 GitHub 帳號
- token 存在瀏覽器不算絕對安全，防護重點是「範圍小、會過期、可作廢」

**數位簽章（解決玩家與審核員無法隔離的問題）**

- 兩把 token 都來自同一帳號、對同一 repo 有寫入權，技術上玩家也寫得出「已通過」檔案
- 解法：審核頁在湘的手機產生並保存**私鑰**（Web Crypto，瀏覽器內建）；**公鑰**寫在遊戲程式碼中（公開無妨）
- 每筆審核結果、暗號、約會 QR Code 都由湘的私鑰簽章
- 玩家 App 只接受簽章驗證通過的資料 → 改得動檔案，也偽造不了湘的章
- 私鑰需提供備份方式（湘換手機時要能還原）

**隱私**

- 照片經 Canvas 壓縮重新編碼，自動移除 EXIF（含 GPS）

### 12.3 技術限制

- **容量**：照片壓縮至約 250KB，約 4000 張達 GitHub 建議的 1GB 上限，兩人使用可撐多年
- **Android 推播**：可行，App 關閉也收得到；由 Actions 發送 Web Push，VAPID 私鑰存 Actions secrets
- **事件推播**（新照片待審、審核完成）：延遲約數十秒，可接受
- **定時推播**（蛋快孵好了）：Actions 排程常延遲十幾分鐘以上，只適合不急的提醒
- **計步**：網頁無法背景讀取，不採用

## 十三、開發階段

### Phase 1｜可玩核心
Android PWA 基礎介面、神秘恐龍蛋開局、原味小湘、保溫與破殼動畫、基礎蛋池、黑影圖鑑、基礎願望、每週賓果、本機存檔。

GPS 縣市判定、本島 19 縣市收藏、天氣與時間事件、約會地點打卡、約會 QR Code。

### Phase 5｜完善體驗
推播通知、更多角色、完整成就、數值平衡、動畫音效與視覺優化。

## 十五、設計原則

這不是單純的抽卡遊戲。玩家必須透過現實探索、養成角色、研究配方與完成任務，逐步擴充收藏。抽卡的驚喜感是獎勵，而不是唯一玩法。

> 要讓玩家感受到「這隻小湘是我自己養出來的」，而不只是「我剛剛抽到了這張卡」。

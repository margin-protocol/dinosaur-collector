# 孵化研究室｜第一階段介面原型

依使用者確認，先做手機介面與操作預覽，研究消耗、成功條件及正式結算留待下一階段確認。

## 入口與畫面

- 正式遊戲：研究者手記 →「研究 · 預覽」，路由 #research；目前頁面標記、返回與關閉沿用共用導航。
- review/research/：使用獨立示範收藏（001、002、005），可切換未解鎖狀態，不讀取 localStorage、不修改真實遊戲進度。
- 共用 js/research.js 呈現兩位搭檔、中央普通蛋、研究筆記與線索；使用既有透明角色／蛋素材，非扁平化概念圖。

## 這版可操作內容

遵循現有企劃的三種收藏門檻；不足時顯示目前收藏數與前往培育入口。達門檻後可選兩位已收集、彼此不同的小湘，可更換或清除位置；清單不列未收藏角色。所有選角行為每次都重讀提供的收藏狀態，失去收藏時會清掉失效選項。

首則筆記「甜甜的相遇」對應草莓小湘（002）與甜點小湘（005），順序不限。選角會更新兩條線索；選好兩位後可查看：

- 對上線索：草莓蛋糕小湘（011）的結果美術預覽。
- 尚未對上：提示還差一點靈感，可回去更換搭檔。

頁面與結果都清楚標示預覽，不消耗能量或蛋，不增加角色、XP、化石，不調用任何遊戲結算 API。尚未收藏的 011 僅在這個明示的配方結果示範出現，不影響圖鑑解鎖。

## 尚未實作／待確認

正式研究成本、要選擇或占用哪顆蛋、計時與成功機制、失敗時回到一般池的結算、永久研究筆記、首次成功日期、研究與正式孵化的交易保護。這版搭檔選擇只存本頁記憶體，刷新清空；不偽造可永久保存的研究成果。

## 驗證

- tests/research.cjs：360／390／430px，844／612 高度；三收藏門檻、已收藏限定、不可重複、清除與鍵盤 Enter／Escape、線索與兩種結果、返回、獨立示範。
- 對全部選角與結果操作前後比對完整 siang-collector:v1 JSON 完全不變。
- tests/interaction.cjs：既有首頁動畫、打招呼、開關選單、返回回歸。
- docs/review/research-{locked,empty,picker,ready,result,short}-*.png：實際手機尺寸截圖；結果彈窗採視窗截圖。

使用 Chromium 手機模擬，Safari／Android Chrome 真機仍待驗收。

## 研究室 1.0｜正式遊戲筆記功能（2026-11-19）

- 在正式遊戲選兩位**已收藏且不同**的小湘，按「開始組合研究」；透過 `updateState` 的全域存檔鎖重新驗證收藏後，寫入 `state.research.trials`，紀錄排序後的組合編號、首次研究日期和線索類別。
- **同一組搭檔僅記錄一次**，換順序不會重複；頁面顯示最新十二組實驗和總紀錄數。重開、重新整理仍保留。
- 初期提供兩則配方筆記：`strawberry-cake`（002、005）與 `rain-garden`（006、003）；其他組合只記錄「接近」或「暫無線索」，不用能量、蛋或徽章。
- 正確搭檔會得到「入住日數／是否需下雨」提示，**不提前揭露尚未完成的隱藏角色名稱或完整美術**。
- 孵化、入住宿日、送紀念蛋和實際角色取得繼續由現存 `js/recipes.js` 與 `js/app.js` 負責；研究按鈕**不發獎**、不變更好感、能量、化石或戰力。
- 原有 `review/research/` 保留單獨假存檔的介面示範，不讀寫正式遊戲；新的 `onStudy` 注入式接口只在正式遊戲提供。
- 測試：`tests/research.cjs`（正式寫入、重複組合、重整保留、未收藏阻擋、獨立示範），以及 `tests/research-notes.cjs`（純規則）。未測實機 Safari/Android。

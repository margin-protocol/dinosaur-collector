# 素材規格｜給美術部（皮寶）

> 工程：德寶（Claude）· 對應 `ART_DIRECTION_V0.7.md` 第 5、9 節
> 日期：2026-11-15

程式已經照「可替換素材」架構做好：**檔案放到指定路徑、用指定檔名，就會自動取代佔位圖，不用改程式。**
每個檔案會先找 `.webp`，沒有再找 `.png`，都沒有才顯示佔位圖。

## 1. 恐龍蛋

路徑：`assets/eggs/<蛋的 id>/<圖層>.png`（或 `.webp`）
目前已登記的 id：`origin`（小湘本源蛋）、`ordinary`（普通蛋）。新蛋種請先告訴工程要用的 id。

### 畫布與對位（最重要）

> **2026-11-15 更新：以本源蛋為對位標準。** 第一批 `origin` 圖層已驗收並上線，四層疊合正確。之後所有蛋種請**沿用本源蛋的畫布與位置**（交付時 1254×1254 正方形即可，工程會縮成 1024 並轉 WebP）：蛋本體約佔畫布 x 20%–80%、y 13%–89%，底座可用滿整張畫布。下面原本的數字作廢，其餘規則不變。
>
> 給下一顆蛋的兩個小建議：(1) `glow` 很亮，程式最多只疊到 55%，否則蛋殼花紋會被洗白，所以發光層可以畫得更集中在蛋的中下部；(2) 底座正面的寶石裝飾會被蛋擋住，想露出來的裝飾請放在蛋的輪廓之外。

- 畫布 **1024×1024**，透明背景
- **同一顆蛋的所有圖層用同一張畫布、同一個位置輸出**，程式是直接把圖層疊在一起，不做個別對位
- **所有蛋種共用同一組對位**，換蛋才不會跳動：
  - 蛋本體範圍：x 272–752、y 140–780（寬 480、高 640），水平置中於 x=512
  - 蛋底與底座接觸點：約 y=760
  - 底座範圍：y 680–940
  - 外部裝飾（藤蔓、環、花瓣）可以超出蛋的範圍，但四邊各留 40px 以上不要貼邊
- 佔位圖 `assets/eggs/_placeholder/*.svg` 就是照這組對位畫的，可以當底圖參考

### 圖層

| 檔名 | 必要 | 內容 | 程式怎麼用 |
|---|---|---|---|
| `shell.png` | ✔ | 完整蛋殼，不要畫裂痕，盡量不要把強光畫死在上面 | 呼吸、晃動、破殼時放大淡出 |
| `glow.png` | ✔ | 只有內部發光，邊緣柔和漸淡到透明 | 用 screen 混合疊在蛋殼上，亮度隨保溫進度從 25% 升到 100%，並有脈動 |
| `cracks.png` | ✔ | 只有裂痕線條，其他全透明 | 60% 進度時由上往下露出約一半，90% 全部露出 |
| `cradle.png` | ✔ | 獨立的金屬花瓣底座 | 固定不動，放在最底層 |
| `ornaments.png` | 選用 | 外部裝飾 | 尚未接上，需要時再加 |
| `foreground.png` | 選用 | 蓋在蛋前面的特效 | 尚未接上，需要時再加 |

注意：

- `glow.png` 請用**透明背景**，不要黑底
- 裂痕是「由上往下」逐步露出，所以**早期裂痕畫在上半部**、後期裂痕畫在下半部，效果最自然
- 圖層之間不要互相畫進對方的內容（例如蛋殼上不要有底座的影子），否則疊起來會重複

### 加分項目（有的話動畫會更好）

- `shell-top.png`、`shell-bottom.png`：蛋殼沿裂痕分成上下兩片，破殼時可以真的分開。沒有的話，破殼就是整顆蛋放大淡出加上閃光

## 2. 小湘角色

路徑：`assets/characters/<檔名>.png`
第一隻：`siang-001-original.png`（原味小湘）

- 畫布 **1024×1024**，透明背景，角色水平置中
- 腳底對齊 **y=940**，頭頂不高於 y=80
- **不要畫外發光、落地陰影或背景光暈**：圖鑑的黑影是程式把整張圖變成全黑產生的，光暈會變成一團黑霧
- 邊緣要乾淨，不要有半透明的白邊殘留
- 檔名規則：`siang-<三位數編號>-<英文短名>.png`

## 3. 小恐龍吉祥物

路徑：`assets/mascot/dinosaur-idle.png`

- 畫布 **512×512**，透明背景，腳底對齊 y=470
- 之後若要多種表情或動作，檔名用 `dinosaur-<狀態>.png`

## 4. App 圖示

路徑：`assets/icons/icon-512.png`、`icon-192.png`

- 正方形、**不透明背景**（建議 `#191518`）
- 主體放在中央 60% 的範圍內，Android 會把圖示裁成圓形或圓角

## 5. 檔案大小

- 原始 PNG 請另外保留，不用壓縮
- 放進 repo 的檔案：蛋每個圖層 **≤ 300KB**、角色 **≤ 300KB**、吉祥物 **≤ 150KB**
- 超過的話交給工程轉成 WebP 即可

## 6. 建議製作順序

1. `origin` 蛋的四個必要圖層 → 先確認分層疊起來的效果
2. `siang-001-original.png` → 確認黑影圖鑑與揭曉畫面
3. `dinosaur-idle.png`
4. App 圖示
5. `ordinary` 蛋，之後才是其他蛋種與角色

第 1 項到了以後，工程會在實機上確認對位和發光效果，有問題再回來調整規格，之後再大量製作。

# 孵化揭曉

培育達標後按「迎接新夥伴」，播放約 2.8 秒的蛋回應、破殼演出，再顯示相遇結果。使用既有蛋分層與角色立繪；尚未有正式美術的角色仍沿用人形剪影。

- 「跳過演出」或 Escape 只略過播放，仍走同一結算流程；reduced-motion 直接進入結果。
- 保留原有抽取機率、本源蛋固定角色、普通蛋 200 能量、重複角色 3 化石規則。
- 動畫結束後透過既有共享存檔鎖核對原蛋 id／since／溫度，只提交一次收藏、化石、孵化數與下一顆蛋。結果畫面的按鈕不發獎。
- 首次相遇與再次相遇有不同標題；「一起回家／收下化石」返回首頁，「安排入住」開啟原有三人入住選單。首次新角色仍沿用原有自動入住規則，滿三人時由玩家安排。
- 結果先保存再呈現，刷新不重發；演出結算前刷新仍保留原本可孵化的蛋。

`tests/hatching.cjs` 驗證 360／390／430px、完整播放／跳過／Escape、重複獎勵、安排入住、刷新、612px 矮畫面、reduced-motion 與跨分頁單次結算。`tests/mobile.cjs` 回歸拍照願望、能量、存檔與孵化。截圖為隔離測試存檔，位於 `docs/review/hatching-*.png`。

本次使用 Chromium 手機模擬，iOS Safari／Android Chrome 真機流暢度仍待驗收。

彈窗驗收截圖採手機視窗截圖；原生 dialog 的 backdrop 只覆蓋視窗，整頁截圖會把視窗以外未遮暗的文件一併拍入，產生假斷層。彈窗開啟期間鎖定文件背景捲動，矮畫面在 dialog 內捲動。

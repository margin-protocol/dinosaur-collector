# 小湘雲端（Cloudflare）設定與使用

2026-11-19 起，玩家不用再各自開 GitHub 私人 repo。所有玩家共用一個後台「小湘雲端」，各自只看得到自己的資料，湘的審核室看得到全部。

- 後台網址：`https://siang-collector-api.a2007014.workers.dev`（Cloudflare Worker `siang-collector-api`）
- 資料庫：Cloudflare D1 `siang-collector`（免費額度）
- 程式：`server/worker.js`；本機測試用 `server/dev-server.mjs`（Node 內建 SQLite 模擬 D1），測試 `tests/siang-cloud.cjs`

## 湘：第一次設定（只做一次）
1. 打開審核室 `review.html` → 第 1 步按「產生審核員通行碼」。
2. 畫面會顯示一組 `REVIEW-…` 通行碼，**只顯示這一次**：按「複製通行碼」存進密碼管理器，再按「我存好了」。
3. 換手機或清掉瀏覽器資料時，在同一處貼上這組通行碼「用通行碼登入」。

## 湘：新增玩家
1. 審核室第 1 步 →「＋ 新增玩家」→ 輸入名字 →「產生邀請碼」。
2. 把 `SIANG-…` 邀請碼傳給玩家（只顯示這一次；弄丟了就按「重新產生邀請碼」，舊的會立刻失效，進度不會不見）。
3. 不想讓某人再連線：「停用這位玩家」（資料保留，可以再恢復）。

## 玩家：連線
遊戲 → 研究者手記 → 雲端與備份 → 貼上邀請碼 → 連線。之後每天自動備份。

## 給所有玩家的暗號
審核室第 3 步勾「送給所有玩家」，每位玩家都能用同一句暗號（每人各算一次；勾「可以重複兌換」則每人每天一次）。

## 安全
- 邀請碼與審核員通行碼，後台只存 SHA-256 雜湊。
- 暗號、紙條、委託、審核結果仍然要有湘的印章（數位簽章）遊戲才接受，後台被改也偽造不了。
- 舊的 GitHub 玩家照樣能用（遊戲與審核室都保留「舊方式」），想搬家時給他一組邀請碼、讓他先「立即備份」舊的、再換邀請碼連線後「立即備份」即可（進度本來就存在手機上）。

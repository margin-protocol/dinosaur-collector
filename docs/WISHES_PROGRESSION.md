# 小湘的願望：每日、研究者等級與角色陪伴

本次依使用者指示直接更新 main，不另開 PR。新版延續核准的深色場景、明體字族與瓷白淡紫按鈕；實作使用現有素材，沒有將概念稿整張當成介面或宣稱其他角色正式美術已完成。

## 玩法與初版數值

- 每日三個不同顏色願望，沿用日期種子、90 組創意名稱與台詞、25% HSV 顏色比例判定。每項完成給 **35 能量＋10 XP**，每天最多三次；照片仍只在本機處理，不上傳、不儲存。
- 新增玩家「研究者等級」，Lv.1 起始；每累計 **100 XP 升一級**，溢出的 XP 保留。這不是小湘角色年齡、等級或好感度，不改寫原有角色成長條件。
- 每級有三個不同的「成長願望」，每項達成後可手動領取 **20 XP＋20 能量**。每個目標只領一次。升級只看 XP，不要求把該級三項全部完成；未完成／未領取的舊級目標永久保留，可在「歷程」選擇已解鎖等級。
- 願望完成、培育、孵化的計數可同步推進成長目標；普通點擊、重整、重複打招呼或切換角色不發 XP。沒有連續登入、指定稀有角色、GPS、天氣或未實作的人工審核門檻。

| 級別 | 章節 | 三個目標 |
| --- | --- | --- |
| Lv.1 | 初次相遇 | 完成 1 個每日願望／注入 10 能量／孵出原味小湘 |
| Lv.2 | 一起生活 | 累計 5 個每日願望／注入 150 能量／孵化 2 顆蛋 |
| Lv.3 | 收藏世界的顏色 | 完成 4 種顏色／累計 12 個每日願望／孵化 3 顆蛋 |
| Lv.4 | 陪伴的練習 | 5 個不同日子完成願望／累計 20 個每日願望／注入 600 能量 |
| Lv.5 | 一起慢慢長大 | 8 個不同日子完成願望／累計 30 個每日願望／孵化 5 顆蛋 |
| Lv.6 起 | 同行旅程 | 第 L 級：累計 10×(L−1) 願望／200×(L−1) 注入能量／L 次孵化 |

所有目標都是累計，不要求連續天數。初版常數與目標集中在 `js/progression.js`，可後續調整平衡。

## 願望頁與角色切換

「今日願望」聚焦一項任務，三顆可操作的進度標記可直接切換；角色台詞、拍照條件與相機按鈕為主要內容。「成長願望」呈現三項長期進度與一次性領獎，底部行動會導向尚未完成的日常或培育。

角色旁的「切換小湘」只列已收集角色；孵化前保留蛋與蛋裡的聲音。角色選擇存在獨立的 `siang-collector:wish-character:v1`，和首頁入住偏好分開。切換只改立繪、署名及對應語氣；當天任務名稱、顏色條件、完成進度、能量、XP 與成長目標都不重抽或重置。未收集／無效的偏好會忽略。其他三位尚未有正式美術，仍顯示 Q 版人形剪影。

鍵盤可用方向鍵切換兩個頁籤；原生 dialog 管理角色選擇的焦點與關閉。沒有固定按鈕蓋住內文，矮畫面正常捲動，保留手機安全區域與 reduced-motion。

## 舊存檔與結算

保留原 `siang-collector:v1` key 及既有欄位，新增：

```text
player.version = 1
player.xp = 累計 XP
player.energyClaimed = 已發放成長能量的獨立識別碼（含舊任務補發）
player.claimed = 已領取的 growth:<level>:<slot> 識別碼
player.stats = { wishes, fed, colors, days }
```

首次遷移不清除能量、化石、收藏、孵化數、當前蛋與當天已完成願望，也不重新發放已結算任務的能量或 XP。累計願望只以有保存的當日紀錄起算；不使用剩餘能量猜測完整歷史。注入計數保留目前蛋可驗證的溫度；已孵化玩家至少保留完成初始 10 能量目標的資格。收藏與累計孵化數直接沿用已保存資料。

後續每日成功結算才增加 XP 與新計數。完成狀態、能量、XP 與領獎紀錄先一起保存，再播放回饋。成長願望採永久獨立 id，和每日顏色 id 不混用。當天任務不受升級或選角影響。相機請求攜帶原任務日期，跨午夜返回／辨識完成時不會套用到隔天任務。

照片完成、成長領獎、培育與孵化都透過 `updateState`，在共享 Web Lock 內重讀最新存檔並同步提交。孵化還會核對原蛋 id／since，另一分頁已孵化就不再結算；交易結束後重新讀取畫面狀態。沒有 Web Locks 的舊瀏覽器維持同步讀寫 fallback，無法宣稱跨分頁具有原子性。儲存空間不可用時保留本次工作階段進度，關閉後仍可能無法保存。

## 驗證

- `node tests/progression.test.mjs`：6 項規則測試，涵蓋舊存檔、不重發獎、每日累計、成長資格／唯一 id、升級與跨日保留。
- `tests/wishes.cjs`：360／390／430px、844／612 高度；角色切換前後遊戲 JSON 不變、選擇刷新保留、未收集角色不可選、任務固定、XP 領取、升級、舊章節、鍵盤頁籤、跨日。
- 真實 Chromium 多分頁：兩個相機請求等待同一把存檔鎖，只發一次 35 能量與 10 XP；成長領獎與培育同時執行不覆蓋對方結果；兩分頁領取同一成長目標只發一次 XP 與能量。
- `tests/reward-migration.cjs`：兩分頁同時載入舊成長紀錄與重整，只補發一次能量，不重發 XP 或修改蛋。
- 瀏覽器時鐘跨午夜：舊相機輸入不發能量或 XP。
- `tests/mobile.cjs`：沿用的照片辨色、3×35、刷新保存、培育、孵化與跨日回歸。
- `tests/room.cjs`、`tests/interaction.cjs`：住戶、原遊戲進度、動畫、打招呼與返回回歸。
- 檢查 JS syntax、`git diff --check` 及指定寬度的 innerWidth／scrollWidth。

實際截圖位於 `docs/review/wishes-*.png`：`daily`／`growth`／`level-two`／`characters`／`egg`，另有各頁 612／844 高度版本。等級與全收藏範例使用隔離測試存檔，不代表玩家角色已被解鎖。

此環境未能執行 WebKit（缺少系統函式庫）；iOS Safari／Android Chrome 真機相機、相機取消及實機動畫流暢度仍待驗收，桌面觸控模擬不能視為真機通過。

## 本機執行

```sh
python3 -m http.server 8000
# 另一個終端（需已安裝 playwright）
node tests/progression.test.mjs
node tests/wishes.cjs
node tests/mobile.cjs
node tests/room.cjs
node tests/interaction.cjs
```

可用 `CHROMIUM_ONLY=1` 只跑 Chromium，`CHROMIUM_PATH=/usr/bin/chromium` 使用系統瀏覽器，`NODE_PATH` 指向預裝 Playwright。

成長能量更新：先前已領取 XP 的有效成長願望，在共享存檔鎖內補發每項 20 能量，記錄 energyClaimed；不重發 XP，刷新與跨分頁不重複補發。單純讀取存檔不發放獎勵。

*「欸？！又是新的耶！！嘿嘿，我是不是很幸運呀♡」*

# 工程交接規格

## 歐皇成就計數

| 項目 | 建議規格 |
|---|---|
| 計數欄位 | `lifetimeNewHatches` |
| 判定 | 一般孵化得到尚未登錄圖鑑的角色 |
| SR 門檻 | 10 次 |
| SSR 門檻 | 50 次 |
| UR 門檻 | 100 次 |
| 是否連續 | 否，終身累積 |
| 是否扣除資源 | 否 |
| 是否保留前一階角色 | 是，三隻獨立收藏 |
| 領取次數 | 每個里程碑一次 |

### 和非酋三部曲對稱

- **歐皇**：一般孵蛋得到新角色，`lifetimeNewHatches += 1`
- **非酋**：一般孵蛋得到已擁有角色，`lifetimeDuplicateHatches += 1`
- 配方小湘、活動獎勵、成就獎勵等保證取得的角色，不列入兩邊的「一般孵蛋」計數。
- 兩邊的進度互不排斥，玩家可以同時收集歐皇與非酋六隻。
- 應根據實際孵化歷史判定，避免重複領獎；若現有存檔沒有來源紀錄，不直接把所有已收集角色當成一般孵蛋成果。
- **UR 的一百次門檻須先確認一般蛋池是否有至少一百種可取得的新角色**；若目前不足，保留長期成就，待角色池擴充後自然解鎖。
- 雲端備份同步兩種累計次數及六個獎勵領取狀態。

## 廚房與出門

- 三隻都使用既有廚房四階段好感制度。
- 每隻提供超喜歡、喜歡、普通、討厭四種語氣。
- 出門回報對應成功、普通、空手等實際結果。
- 不讓幸運角色改寫遊戲的抽蛋機率，避免讓三隻成為必備角色。
- 可另外設計純視覺性的孵化祝福動畫，不影響機率。

## 好感與願望

- **Lv.2、Lv.3、Lv.4、Lv.5 均有獨立台詞，不使用系列共用文案覆蓋。**
- 每隻提供八句不同口吻的每日願望。
- 願望可於任何地點完成。
- 不要求玩家付費或抽蛋來完成願望。

**普通歐皇：** 從不知道自己幸運，到學會珍惜與分享。

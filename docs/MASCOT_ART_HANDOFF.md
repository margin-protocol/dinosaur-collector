# 小恐龍吉祥物｜定稿美術交接

狀態：**湘已確認定稿**，可直接作為首頁小恐龍待機立繪。

## 正式素材

- 路徑：`assets/mascot/dinosaur-idle.webp`
- 畫布：512 × 512 px，真正透明背景
- 角色腳底：y = 470
- 角色朝向：面向右邊，搭配首頁左側蛋的位置
- 檔案大小：約 35.7 KB（符合小恐龍 ≤150 KB 的建議）

## 角色造型（此版優先於舊示意）

- **綠色 Q 版暴龍**、奶油白肚皮、短小前爪、胖胖的腳與尾巴
- **沒有背刺、沒有斑點、後腦勺平滑**（製作人已明確移除）
- 閉眼開心大笑、淡淡腮紅、小暴龍牙齒
- 酒紅色蝴蝶結、金色細節與紅寶石吊飾
- 不要自行加回頭部突起、背刺、斑點，也不要改回棕色暴龍
- 現有定稿是獨立坐姿，**不必改成抱蛋**；將角色擺在蛋左側即可
- 保留原圖少量裝飾星芒，未來如需動畫可另提純角色版本需求

## 工程注意

程式已按 `ASSET_SPEC.md` 的檔案尋找順序優先讀取 WebP，故 `dinosaur-idle.webp` 可直接取代佔位圖。請確認小恐龍在 Android 窄螢幕仍不遮住孵化進度、蛋或前景培養架。

源 PNG 為美術原檔，與 WebP 不同：WebP 是上線壓縮版。

# 主題配色

入口：研究者手記 → 主題配色。四個按鈕直接套用，顯示「使用中」，可用完成、關閉或 Escape 返回原畫面。開啟時暫停首頁角色，關閉後恢復；短螢幕在對話框內捲動。

| 主題 | 氛圍 | 深色底色 |
| --- | --- | --- |
| 月霧紫（預設） | 溫柔月光 | `#151722` |
| 薄荷星海 | 安靜綠意 | `#101e20` |
| 靜夜藍 | 清冷星空 | `#111b2b` |
| 玫瑰暮色 | 柔和暖意 | `#24191f` |

`css/themes.css` 集中管理背景、面板、層級、文字、強調色與按鈕色，沿用既有字體、尺寸與互動。首頁房間採用各主題的色調遮層，角色與蛋的圖片不套變色濾鏡。願望辨色目標與三顆進度寶石維持任務原色；破殼與錯誤／危險操作也保留語意。

偏好獨立存在 `siang-collector:theme:v1`，不寫入主遊戲存檔。HTML 頭部在樣式載入前讀取合法偏好，減少重整閃回預設色；`js/themes.js` 接管選擇、瀏覽器 theme-color 與跨分頁同步。未知值回到月霧紫；儲存失敗仍套用本次選擇並說明無法記住。偏好已列入既有雲端備份／還原白名單，舊備份沒有此欄位也能還原。

## 驗證

`tests/themes.cjs` 在 Chromium 手機觸控模擬以 360 / 390 / 430px 檢查四款配色的首頁、願望、培育與選單，涵蓋：即時選取、唯一目前狀態、重新載入、主存檔完全相同、入住偏好不變、願望寶石顏色不變、蛋素材無變色濾鏡、跨分頁、角色暫停／恢復、612px 短螢幕、水平溢出、無效偏好與儲存失敗。

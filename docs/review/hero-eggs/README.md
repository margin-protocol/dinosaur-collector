# 勇者小隊：徽章換蛋，再培育孵化

玩家澄清後的正式流程：騎士 20、魔法師 20、勇者 40 枚徽章（勇者仍需打倒前兩章 Boss），換到 gifts.eggs 裡固定 character 的 keepsake 蛋。到培育 → 選擇蛋 → 紀念蛋，選指定小湘的專屬蛋，注入 100 能量後正常破殼。沿用紀念蛋正式三層素材及現有存檔結構。

三位已移出所有隨機蛋池。已持有角色不會被移除；未孵化的庫存／培育中／暫放蛋皆阻擋重複扣徽章。兌換當下不加入圖鑑與入住。

驗證：tests/badge-heroes.cjs，實際兌換、明確顯示待孵化、選蛋、注入能量、破殼與指定角色解鎖；單元檢查庫存／主架／暫放／已取得的防重複兌換，勇者兩章 Boss 限制與三人連攜保留。選蛋頁 360／390／430px 無水平溢出，截圖 390px。

# 旅行相簿圖片撐寬修正 · 2026-11-17

影片中的問題是「派小湘出門 → 旅行相簿」的卡片：原本 grid 使用 `1fr` 的自動最小尺寸，卡內角色圖片又以相對高度搭配自動寬度參與尺寸計算，解碼後把縮圖撐成 2048 × 1536px，390px 螢幕的對話框因此有 2072px 的橫向內容。

改用可縮小至零的 grid 欄、明確受父層約束的卡片與按鈕寬度，角色圖層定位在固定 4:3 相框內，圖片大小不再參與相簿欄寬計算。結果頁共用同樣相框；沒有隱藏超寬內容來掩蓋問題，沒有修改出門、相簿資料或獎勵。

`tests/travel-album-layout.cjs`：Chromium 360 / 390 / 430px，1 張及 40 張相簿、1024／1254px 角色素材、雙人與單人、原圖載入後的尺寸、原生對話框內無水平溢出、4:3 縮圖、結果重看、關閉、612px 短螢幕與模擬安全區；重看前後主存檔相同。`tests/errands.cjs` 回歸出發、返家與收獎，`tests/updates.cjs` 回歸更新提示。

尚未以實體 iOS Safari 驗收；截圖是 Chromium 手機觸控模擬。

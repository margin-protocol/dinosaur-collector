# 第一章動畫繪本｜獨立試看

《沒有寄出的布丁邀請函》：六幕、18 段短句（含四段片尾彩蛋）。故事延伸自 `js/battle.js` 的焦糖大王結局：焦糖黏住邀請卡、小怪誤會命令、還回點心並重新邀請，最後替玩家留位子。主角使用原味小湘與第一章敵人，未假設玩家的實際出戰隊伍。

本機從 repository 根目錄執行 `python3 -m http.server 8000`，開啟 `/docs/review/chapter-one-storybook/`。線上同路徑；直接按「翻開這個故事」。

- 點畫面／下一句：先顯示全文，再前進；可上一句、跳場景、看彩蛋、重看或關閉。鍵盤支援左右鍵、Enter／Space（畫面聚焦時）及 Esc。
- 自動播放：約 90 秒，依字數保留閱讀時間；可暫停自動。切到背景停止文字／倒數／動畫，回前景才接續。關閉後停止計時。
- 系統減少動態時使用靜態插畫、立即顯示全文；仍可選擇自動翻句。短螢幕與安全區域皆在正常排版流中保留空間。
- 新繪空王宮、宴會、片尾抱抱插畫，另有害羞焦糖大王透明姿態。前半以正式角色立繪、紙偶位移、連串邀請卡與光塵演出，後半以新插畫和緩慢鏡頭演出。這是動畫繪本原型，沒有配音或音樂。
- 原生 PNG 與尺寸清單：`art/chapter-one-storybook/`。WebP 約 1.14MB，保留原生 1122×1402／1254×1254；未拉伸冒充解析度。

這份示範沒有匯入遊戲、存檔或領獎模組，沒有 localStorage／sessionStorage 讀寫，也未註冊 Service Worker。未接首次通關觸發與檔案館入口，讓美術與閱讀節奏可先單獨驗收。

`tests/chapter-storybook.cjs` 驗證 360／390／430px、360×612 短螢幕、44px／34px 模擬安全區域、所有圖片解碼、減少動態、逐字／自動／暫停／背景停止、完整彩蛋／重看／關閉及存檔完全不變。Chromium 手機模擬通過；手機截圖見 `screenshots/`。

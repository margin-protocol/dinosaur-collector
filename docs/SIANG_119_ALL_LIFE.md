# No.119 萬物共生・小湘（SSR・動物系列）

- 來源：系列支線《萬物不標價》五關全通＋五件信物收齊，送紀念蛋（不進任何蛋池）。立繪湘 11/27 畫。
- 設定（皮寶企劃）：不是森林的女王、不是動物的主人，是願意理解不同生命需求的森林照護者。
- 圖鑑台詞（皮寶）：「你不必可愛、不必聽話，也不必為誰帶來快樂。能夠好好活著，就已經很好了。」
- 其他台詞（介紹、好感、出門、料理、許願、戰鬥）是德寶 11/27 暫稿，等皮寶改。
- 口味：喜歡菇香、討厭刺激；隱藏最愛＝魔法蘑菇＋月光露＋牛奶（森林早餐）。

# 貓爬小湘｜No.097 正式交件

湘寶已定稿：SSR、隱藏配方（recipe）系列。搭檔為 Koda 小湘 No.095 與爬爬小湘 No.096，在研究室調配 3 天（連續 72 小時），完成後收到固定孵出 No.097 的紀念蛋，再按現有紀念蛋規則注入 100 能量孵化。不是首頁共同入住累積日數，不加入隨機蛋池，也不屬於討伐徽章兌換。

## 美術

正式檔案：assets/characters/siang-cat-gecko.webp，1024×1024、透明 alpha、全身置中；沒有背景、地面陰影與外發光。以湘寶提供的圖作為造型參考：深棕長髮、灰棕眼、金框眼鏡、奶油白與焦糖色居家服、貓爪配件與照護筆記，抱著虎斑貓 Koda，爬爬待在獨立展示箱中。

已透過影像工具整理參考圖：移除白底，保持兩隻動物分開；獨立封閉展示箱補上通氣細節，移除箱內吊燈；素材匯出時保留透明安全邊距。展示箱是角色識別道具，不當作實際飼養尺寸或設備的教學規格。兩個動物不擬人化、不說話、不共睡或直接接觸。

## 文案與程式來源

完整圖鑑故事《家裡有兩個寶寶》、神秘線索、初見、待機、羈絆、出戰、勝利、戰敗、可選委託和 Lv.2／4／5 文字保存在 data/characters/cat-gecko-097-dialogue.json。故事保留交件內容，合併短行為閱讀段落；Lv.5 截斷尾句補為「嘿嘿，我真的好愛我的兩個寶寶♡」。另補 Lv.3 玩家與小湘共同整理照護筆記的小故事。

js/cat-gecko.js 是遊戲載入的同內容純資料模組，修改時與 JSON 同步。圖鑑、未知線索、好感台詞、初見和討伐專屬台詞已接入現有流程；待機／一般羈絆／可選拍照委託文案保留為資料，不新增照片判定或主動任務。

## 驗收

研究室必須同時持有 095 與 096，已有調配或搭檔忙碌時沿用原本阻擋。未滿 72 小時不發蛋；完成旗標、專屬蛋與清空研究室由既有存檔交易一起儲存。重複完成不再發蛋。配方小湘仍需孵化才會加入圖鑑與首頁。既有角色、蛋池與進度維持原值。

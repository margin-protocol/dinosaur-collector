# 第二章繪本美術｜小聲一點，也聽得見

六幕結尾與〈音量調好了……大概〉片尾彩蛋的七張美術，延伸自 `js/battle.js` 的雷雷大魔王結局。正式角色參考、分鏡、尺寸、透明狀態與檔案大小列於 `manifest.json`。

| 檔名 | 用途 |
| --- | --- |
| valley | 第 1–2 幕共用空背景；吊橋、空石頭座位、水窪、岩台與燈的位置供後續鏡頭演出參考；亦可供彩蛋練習打招呼使用 |
| thunder-shy | 第 1–2 幕委屈雷雷；唯一透明獨立角色，可疊在背景上飄浮、靠近與搖晃 |
| heard-you | 第 3 幕，小湘扶正皇冠：「嗯，聽見了」 |
| helping | 第 4 幕，遞手帕、畫地圖、擦石頭與掛路牌；路牌文字可另疊字幕／DOM／SVG |
| see-you | 第 5 幕，夕陽吊橋道別，雷雷抓著欄杆、披風掛住橋繩 |
| welcome-home | 第 6 幕，朋友回來，攤開披風、在石頭旁喝茶野餐；已修掉雷雷多餘的中央手部 |
| bonus-aftermath | 片尾大雷聲之後：小湘頭髮炸蓬、地圖黏臉、蘑菇壓帽子、雷雷捂嘴、小恐龍守著點心籃 |

原生 PNG 保存在 `originals/`；同構圖 WebP（quality 84）在 `assets/storybooks/chapter-two/`。完整插畫原生 1122×1402，透明雷雷 1254×1254；不拉伸或插值放大。

PNG 是合成原圖，沒有可獨立移動人物／帽子／手的 PSD 分層。完整插畫適合平移、微推鏡頭與字幕演出；只有透明雷雷可獨立位移。路牌只畫蘑菇圖案，文字「歡迎來玩／請勿踩菇」留給繪本排字，避免把錯字畫死在素材裡。

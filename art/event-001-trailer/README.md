# EVENT 001 宣傳影片｜十萬兩紅妝 · 此生護卿

60 秒直式動態字卡預告，1080×1920／30fps，H.264＋AAC，適合手機直式播放。使用者同意放寬40秒，因此六位居民各3秒，片尾卡池4秒、時間表6秒。

## 美術與音訊

沿用專案現有正式場景、海棠新娘117、聞止水MO-001、六位墨痕居民、紙傀、主視覺及上下卷卡池圖，未重繪或改動原素材。片中使用立繪淡入、場景平移、宣紙墨暈、霧氣、落花、向量紅綢與墨色劍光；不是角色骨架／逐格演出的影片。標題主視覺保持完整橫圖，不裁掉雙人。沒有加入尾聲告白或揭露婚契真相。

原創氛圍配樂由程式合成五聲音階的撥弦音色、紙張與劍風音效；不是實錄古琴，也未使用第三方音樂。此版本沒有配音。音訊為立體聲，輸出 loudnorm -18 LUFS、true peak -1.5 dBTP。

## 重製

依賴 Python3、Pillow、NumPy、ffmpeg、Noto Serif/Sans CJK（TC）。不需要網路、帳號或API金鑰。

```sh
python3 art/event-001-trailer/source/render.py --audio --stills --render
```

主檔是1080p。可加 `--width 720` 輸出較小預覽。素材位於本儲存庫相對路徑；程式只寫入本影片驗收資料夾。本次不變更遊戲、活動規則或存檔。

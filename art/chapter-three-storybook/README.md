# 第三章繪本美術｜今天，可以不用笑

延伸既有玩具星球結局及湘確認的六幕繪本、〈今天學會哭哭了〉彩蛋。八張素材依序對應於 `manifest.json`，並列出正式角色參考、分鏡、原生尺寸、透明狀態與檔案大小。

| 檔名 | 用途 |
| --- | --- |
| control-room | 第 1–2 幕共用空背景；大螢幕、工作紀錄、音樂盒、窗景與休息區 |
| director-confused | 第 1–2 幕透明總監：坐下、攤開小手、兩個疑惑小圓眼 |
| old-song | 第 3 幕：金色鑰匙碰上音樂盒，衛兵唱起舊旋律 |
| listening | 第 4 幕：兔兔休息、衛兵讀譜、總監抱住流淚的軟糖熊；已修正多餘手部 |
| pudding | 第 5 幕：「那你自己快樂嗎？」與遞出去的布丁 |
| no-grades-party | 第 6 幕：每位玩具保留不同的感覺，沒有強迫全員笑臉 |
| happy-tears | 彩蛋前半：兔兔送來蠟筆畫，總監顯示幸福的哭哭表情 |
| bonus-laugh | 彩蛋後半：小恐龍用乾手帕擦螢幕，總監被逗笑，朋友們圍著牠 |

原生 PNG 在 `originals/`；同構圖 WebP（quality 84）在 `assets/storybooks/chapter-three/`。背景與多數插畫 1122×1402，listening 為 1072×1467，透明總監為 1254×1254；保留實際輸出，不強制拉伸／裁切或插值放大。播放器應依各圖尺寸選擇完整顯示或鏡頭構圖。

只有 `director-confused` 是獨立透明角色，其餘為背景或完整情境插畫。PNG 是合成原圖，沒有可獨立移動角色／手／帽子的 PSD。情境插畫適合微推鏡頭與字幕演出，不能當成逐格動作影格。

螢幕分數、工作紀錄中的中文、對話與文字表情符號交給繪本的 DOM/SVG／字幕排版；圖片保留空間，避免把錯字或固定分數畫死。工作紀錄沒有獨立近照素材，第 2 幕可沿用背景、透明總監與文字演出。

故事對齊 [歡笑總監企劃](../../docs/COMBAT_CHAPTER03_DIRECTOR_GIGGLE.md) 及 `js/battle.js`。既有「那你自己快樂嗎？」到布丁派對的原始結局保留；本次沒有修改劇情文字、通關觸發、角色數值、獎勵或遊戲存檔。

本次交件範圍為八張美術及 [驗收頁](../../docs/review/chapter-three-art/index.html)，正式尾聲播放器由遊戲功能另行接入。

交件檢查：八張 PNG／WebP 的尺寸、透明狀態與清單大小一致，全部正式角色參考路徑存在。360／390／430px 及 360×612 短螢幕的圖片解碼、放大、Esc／關閉、焦點返回與無水平溢出均通過；驗收頁沒有存檔讀寫。手機截圖見 `docs/review/chapter-three-art/screenshots/`。

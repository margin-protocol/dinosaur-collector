# LV5 三人羈絆插畫

目前 13 組羈絆已交付 12 張依既有角色參考圖生成的完整情境插畫；勇者隊先定調，其餘沿用相同精緻 Q 版風格。圖內不含卡名、戰力、卡框或介面文字。

「離島守護聯盟」（092 馬祖／093 澎湖／094 金門）專屬圖尚未交付；目前遊戲用三位正式立繪組合。補圖時使用 `assets/bonds/islands.webp`，同步加入 `js/bond-art.js` 與本目錄 manifest。

manifest.json 記錄角色編號、參考素材、原圖與網頁檔案、實際尺寸與大小。originals/ 保存生成的完整 PNG；assets/bonds/ 為相同構圖、原生解析度的 WebP 壓縮版（quality 84），未裁切或放大。

原規劃目標 1536×1152；本次工具實際輸出 1448×1086，維持精確 4:3。保留原生清晰度，不以插值放大冒充更多細節。

交付限制：PNG 是完整合成圖，並非角色／背景可獨立移動的 PSD。真正的角色、背景與原畫光效分層稿尚未交付；遊戲卡框、文字、互動反光是獨立 CSS／DOM 層，後續可分別調整。
